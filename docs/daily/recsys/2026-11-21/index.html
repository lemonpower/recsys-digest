让智能体协同优化多模型特征

本期关注 Meta 如何用智能体提出并筛选特征，再通过可重复的实验衡量候选特征对模型表现和计算成本的影响。

目录

Section 1: 📊 Trend Analysis

  • 🔥 Agent 化特征工程走向 fleet 级系统化：Meta 的工作把 LLM agent 从"提假设"扩展到"跨模型 fleet 的特征生成—排序—混合—调优—成本裁剪"全链路，并用确定性工具执行实验保证可验证性。这标志着特征工程从人工/自动化工具向"agent 编排 + 资源约束优化"演进，多任务场景用 Pareto 前沿做特征融合是关键工程范式。
  • 💡 生成式范式全面渗透召回/重排/出价：今日 10 篇中 6 篇涉及生成式（整页生成式重排、连续生成式检索 CACO、扩散 AIGB、语义 ID 生成式召回、LLM 会话嵌入召回）。核心矛盾从"如何生成"转向"如何控制生成的质量/覆盖/多样性/冷启动自举"，如 CACO 的集合级覆盖优化、ISGE 的 SNR 崩溃自举、LQ-Rec 的量化误差可分解理论。
  • ⚙️ 深度扩展与效率优化成为精排主线：DNA 指出 cross-attention 堆叠的瓶颈在 KV 侧并让序列随深度演化；FI-ITEP 用特征重要性指导嵌入剪枝省 20-40% 内存。两者共同指向"在同等算力预算下榨取更多模型容量"，且都给出了线上/生产级验证。

Section 2: 📋 今日速览

  • Meta 面向 fleet 级排序模型提出 LLM agent 驱动的端到端特征优化系统，agent 提假设、确定性工具执行实验，并用 Pareto 前沿融合多任务特征重要性。生产模型归一化熵 +0.31%、管线成本 -2.3%，线上 A/B 主指标 +0.20%。↗
  • Meta 研究整页联合优化，提出 whole-page policy improvement，将页面级目标精确分解为逐位置训练目标，每位置按完整页面得分比较候选。在 KuaiRand-1K、RL4RS-SeqSlate 及工业日志数据上优于生成式重排基线。↗
  • Alibaba 针对淘宝搜索 CTR 提出 DNA 双流注意力，让行为序列随深度演化、每请求更新一次序列供所有候选共享，保持线性复杂度。同等 FLOPs 下 AUC +0.08~0.26pt，线上 CTR +0.8%、GMV +0.5%。↗
  • Alibaba/PKU 针对自动出价冷启动，理论归因扩散 AIGB 迭代停滞为 SNR 崩溃，提出 Judger-Explorer 稀缺引导探索实现自举。工业 AuctionNet 基准上 3 轮迭代即超越全数据基线，代码已开源。↗
  • Autodesk 在生产内容推荐中提出 LSER，用预训练 LLM 生成会话/历史级嵌入作为召回用户塔辅助特征，并设计近线服务异步刷新向量。全目录消融验证 LLM 特征增量价值，但未报告线上 A/B 指标。↗
  • Meta 提出 FI-ITEP，用特征重要性指导各嵌入表剪枝比例，替代基于表大小的启发式。三个大规模模型实现 20-40% 内存节省且精度不降，训练 GPU 从 112 降至 80，单模型省 1000+ GPU 小时。↗
  • Nikkei 用 2000 万浏览会话持续训练 Llama 3 8B 生成新闻标题，发现生成分布比日志更集中，高频标题被更强记忆化并复现流行度偏差。目标级去重可缓解集中但显著损失精度与训练集规模。↗
  • Samsung Research America 提出参数化用户记忆管理系统，用固定容量 k-hot LoRA 子空间存储事实并独立控制时间衰减，配轻量控制器决定记什么、记多深、记多久。长程轨迹数据集上达 oracle 性能 86%，优于 CL/RAG 基线。↗
  • 湖南大学/PKU 提出 CACO 覆盖感知后训练框架，用检索频率作相关性代理构造无标签覆盖目标，协调多查询避免 ANN 邻域重叠。8 个公开基准与 24 分区工业数据上 Recall@100 最高 +23.7%，查询重叠 -53.3%~64.9%，延迟仅 +0.5%~3.0%。↗
  • Toyota/UC San Diego 提出 Late Quantization 非自回归生成式召回，量化仅作用于物品侧，给出加性误差分解与成对排序定理界定量化导致的排序损失。四个基准上排序质量随语义 ID 长度单调提升，单模型支持随时压缩无需重训。↗

Section 3: 📰 Daily Digest

1. Cost-Aware Agentic Feature Optimization System for Fleet-Scale Ranking Models

🔗 原文： https://arxiv.org/abs/2611.26531

🏷️ 来源： 🏭 工业界 | Meta

⭐ 评分： ⭐⭐⭐⭐⭐ (5/5)

🎯 推荐理由： Meta 提出 LLM agent 驱动的 fleet 级特征优化系统，线上 A/B 主指标 +0.20%，工业落地价值高。

📝 摘要： 大型平台往往同时运行大量排序模型，共享数万特征池，但特征管线成本（跨模型共享）与 serving QPS（每模型独立）构成双重资源约束。本文构建端到端 agentic 系统：LLM agent 提出假设、确定性工具执行并验证实验；LLM 从组合空间生成并初筛 cross feature，多种重要性方法排序后经 feature blending 融合，多任务模型用跨任务 Pareto 前沿做选择；LLM Researcher agent 在 10-25 次异步试验中于资源上限内调优，最后 trimming 步骤守住成本预算。生产模型上归一化熵平均 +0.31%，trimming 降管线成本 2.3% 且无超噪声回归，优化模型已上线，线上 A/B 主指标 +0.20%。创新点在于 agent 编排 + Pareto 多任务融合 + fleet-aware 成本裁剪三者结合，对多模型共享特征池的工程团队有直接借鉴价值。

2. Learning Generative Ranking Policies for Whole-Page Optimization

🔗 原文： https://arxiv.org/abs/2611.25527

🏷️ 来源： 🏭 工业界 | Meta

⭐ 评分： ⭐⭐⭐⭐ (4/5)

🎯 推荐理由： 提出整页策略改进方法，通过逐位置训练目标优化生成式重排，在多个数据集上优于基线。

📝 摘要： 推荐页是整体消费的，物品间既竞争注意力又相互补充，最优页面不等于单物品最优的拼接，而页面组合数呈组合爆炸，必须"生成"而非枚举。现有生成式重排要么对采样页所有位置用同一页面级信号，要么模仿训练前固定的目标页，随生成器改进而失效。本文提出 whole-page policy improvement：单一局部页面级目标反复将当前生成器推向更高分页面，该目标可精确分解为每位置一个训练目标，每个目标在相同部分页上按完整页面得分比较候选，使每个位置学会选"对整页更好"的物品。在 KuaiRand-1K、RL4RS-SeqSlate 两个公开数据集（覆盖多目标选择与约束排序）、工业日志页面数据集及已知最优的合成基准上均优于生成式重排基线，证明增益来自更好的整页决策。局限在于尚无线上 A/B 验证。

3. DNA: Unlocking Depth Scaling in CTR Models

🔗 原文： https://arxiv.org/abs/2611.25659

🏷️ 来源： 🏭 工业界 | Alibaba

⭐ 评分： ⭐⭐⭐⭐ (4/5)

🎯 推荐理由： 提出 DNA 双流注意力机制，让行为序列随深度演化，解决 CTR 模型深度扩展瓶颈，并在淘宝搜索线上验证有效。

📝 摘要： 长行为序列是 CTR 最强信号之一，cross-attention 以线性复杂度使其可用于工业排序，但堆叠层数收益递减——淘宝搜索上从 16 层加到 28 层仅增 0.02pt AUC。作者指出瓶颈在 KV 侧：每层把同一序列投影成 key/value，加深只是对固定序列的更多次读取。为此提出 DNA（Dual-stream Nexus Attention），让序列本身随深度演化：每层先由 request 表示（query、用户特征、场景）读取序列，再由每个行为 token 关注更新后的 request 并据此更新自身，下一层读到的是被当前 request 重塑过的序列；更新每请求一次、所有候选共享，读写均保持序列长度线性复杂度。同等前向 FLOPs 下 AUC 较 cross-attention 提升 0.08-0.26pt，且在后者饱和的深度区间仍持续提升。DNA-4 已部署淘宝搜索，线上 A/B CTR +0.8%、GMV +0.5%。属对 cross-attention 的增量改进，但工程收益明确。

4. Iterative Scarcity-Guided Exploration: Bootstrapping Generative Auto-bidding from Narrow Support

🔗 原文： https://arxiv.org/abs/2611.26060

🏷️ 来源： 🤝 产学合作 | Alibaba, PKU, City University of Hong Kong

⭐ 评分： ⭐⭐⭐⭐ (4/5)

🎯 推荐理由： 理论揭示扩散AIGB迭代停滞的SNR崩溃机制，提出稀缺引导探索实现冷启动自举，工业基准验证有效。

📝 摘要： 自动出价是广告拍卖核心组件，冷启动场景常用迭代训练弥补历史数据窄支持、低质量的问题，但代表性扩散式 AIGB 方法在迭代中无法外推到窄支持集之外，停滞在次优水平。本文从理论上将停滞归因于 SNR 崩溃：微弱的径向回报信号被曲率诱导的惩罚项淹没。为此提出 ISGE（Iterative Scarcity-Guided Exploration），引入"引导交接"机制——当回报信号崩溃时，由稀缺性接管作为探索信号，将 SNR 抬升至临界阈值之上；具体交替运行 Judger（为轨迹打稀缺分）与 Explorer（引导生成高稀缺、高回报轨迹），用自生成轨迹从窄支持集自举。工业 AuctionNet 基准上，从冷启动数据集出发，3 轮迭代即超越全数据基线，代码已开源。局限是未在真实线上广告系统部署验证，理论分析基于简化假设。

5. From Sessions to Serving: Integrating LLM-Based Embeddings into Retrieval for Production Content Recommendation

🔗 原文： https://arxiv.org/abs/2611.26096

🏷️ 来源： 🏭 工业界 | Autodesk

⭐ 评分： ⭐⭐⭐⭐ (4/5)

🎯 推荐理由： 工业级LLM会话嵌入检索系统，近线服务设计有参考价值，但缺线上A/B数据。

📝 摘要： 大型市场网站的内容推荐需将异构候选（客户案例、产品页、行业页、学习内容）与稀疏且快速变化的用户行为对齐，对召回阶段的用户兴趣表示提出更高要求，而非只压给下游排序。本文提出 LSER，一个部署于 autodesk.com 的生产内容推荐系统：从预训练 LLM 导出会话级与历史级嵌入，作为召回阶段用户塔的辅助特征，与现有学习式序列编码器并存。为在实时行为下保持用户侧嵌入新鲜度，设计近线服务路径，异步刷新主推荐服务器的序列向量与 LLM 派生向量。通过覆盖全多内容类型目录的消融实验验证 LLM 特征的增量价值，结果表明将 LLM 嵌入作为额外召回信号配合生产级近线服务在技术上可行并能提升模型表现。局限在于方法为在现有编码器上叠加 LLM 特征的增量改进，且未报告线上 A/B 量化指标。
