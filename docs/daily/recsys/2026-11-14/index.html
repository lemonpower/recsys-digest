生成式召回怎样找回长尾商品

生成式召回的长尾表现受多处限制。ReSID 检查从编码到匹配的各个环节，TriGen 和 KuaiRecV2 则分别聚焦即时行为与随时间变化的候选池。

论文要点

  • ReSID。沿语义 ID 构建、解码和匹配三个阶段排查长尾商品的可达性，用并行 ID、去偏束搜索和部分匹配改善覆盖。 论文
  • TriGen。面向行为触发的推荐场景，用动态门控在即时意图和长期偏好之间分配权重，论文报告了六个市场的线上实验。 论文
  • KuaiRecV2。在动态候选池和连续交互流上评测持续学习，同时跟踪召回准确性、多样性与多任务表现。 论文
