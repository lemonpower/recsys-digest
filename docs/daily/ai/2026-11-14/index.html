llama.cpp 与 ggml 同步发布 v1.0.0：核心不是新功能而是承诺——用语义化版本号显式表达 API/ABI 不兼容 ｜ 本地推理生态进入「可依赖」时代

Cursor 首次完整披露 10/29 安全事件攻击链：第三方 Fireworks 泄露 access key → 只读桶拷走 coding agent trace → 恶意 Claude Code 扩展上架 11 小时 ｜ agent 工具链供应链风险的难得一手复盘

起点是 Fireworks 泄露了 Cursor 签发的 access key，攻击者用它从只读存储桶拷走 2025 年的 coding agent trace（非 Privacy Mode 会话，<0.05% 用户），其中少量未脱敏凭证（<0.01% 客户 API key 暴露）成为跳板，进而触及内部 SaaS 工具、归档的非生产源码仓、客服数据与部分 agent 对话摘要。最值得记的一环：攻击者用窃得凭证在 Cursor 扩展市场缓存里投放了 Anthropic Claude Code 扩展的恶意副本（2.1.312/2.1.313），约 5000 名请求特定缓存版本的用户可能中招，存活约 11 小时，Open VSX 源站未被污染。文末给出未受影响范围与自查/轮换步骤，可作为「第三方 vendor key → 数据外泄 → 扩展投毒」的完整威胁模型模板。

来源：cursor.com

Bedrock AgentCore runtime V2 用 microVM snapshot/restore 重构会话冷启动，并给出四种 pattern 的选型表 ｜ agent 部署工程的可照搬底稿

不再每个 session 拉镜像起容器，而是在 create/update 时启动一次容器、等 /ping 健康后清空文件缓存、冻结 microVM 并把内存+磁盘存成 snapshot，新 session 直接 restore 快照，进程从冻结处恢复（imports/对象/客户端都在），镜像文件按块 lazy 读取。由此推出三条关键事实：内存整体回来、文件读缓存不跨 session 保留、镜像文件首次读才拉取。选型表很实用：2 秒可接受就切 V2 并把初始化放到 app.run() 之前；需要大文件/CLI/浏览器就加 build hook 在快照构建期预热；要亚秒级且用户在发首个请求前已有交互就后台预启动 session。注意 V2 下每次 create/update 要花几分钟建快照。

来源：aws.amazon.com

NestDaddy 全量实测 37,000 个远程 MCP server：89.6% 能应答 initialize，1/3 直接要 key，中位每 server 7 个 tool ｜ MCP 生态第一份全量分布数据

每天用 MCP client 连官方 registry 全部远程 server，首轮覆盖 62,377 条注册项：12.6% 被判批量灌水隐藏，实际连了 37,383 个，89.6% 能应答 initialize，其中 1/3 直接返回 401/403 要 key 才肯列 tool，3,555 个完全不应答（404/405 多因 registry 填错路径）。应答中位约 500ms，说明协议本身不是瓶颈。共发现 292,447 个 tool，4,325 个 server 暴露 20+ 个 tool——而每个 tool 描述都进上下文，堆 5 个 30-tool 的 server 就等于每轮对话塞 150 条描述，既烧 token 又降低选对 tool 的概率。对 MCP server 作者最实用的一条：initialize 和 tools/list 对所有人开放、只在 tools/call 时才要 key。

来源：nestdaddy.com

来源：dwarkesh.com

Physical AI 架构综述：VLA 三代演进 → world model 作仿真器 → World Action Model 合流，核心是「数据可得性 vs 推理成本」的对称权衡 ｜ 一次性建立 VLA/WAM 技术地图

系统梳理从「隐式学物理」到「显式预测物理」的迁移：VLA 三代（action-as-token → 独立 flow-matching action expert → 慢推理/快控制双系统），world model 作为仿真器与训练场，以及把两者合流的 World Action Model（以 NVIDIA《World Action Models are Zero-shot Policies》为标志，DreamZero 等五个设计选择）。核心洞察：VLA 推理便宜但需每帧带 action 的稀缺真机数据，WAM 能从无标注视频预训练但推理贵数倍，而 2026 年新模型（Cosmos 3 的 mixture-of-transformers、VLA-JEPA 的 latent future prediction）正在收窄这一差距。与本周 Cosmos 3、PAN 2、Runway Praxis-1 三条路线对照读，可拼出完整选型坐标。

来源：gargighosh1.substack.com

The avalanche that hit math is coming for AI development
