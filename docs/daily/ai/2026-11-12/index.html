📊 今日概览

Anthropic 的 IPO 路演文件成为今日最硬的一手材料：定价 70–78 美元、最高 1.4 万亿美元估值、年化收入运行率约 810 亿美元，Google 与 NVIDIA 按发行价认购 260 亿无投票权股份；路演视频中 Tom Brown 更披露 Claude 同时运行在 Trainium/TPU/NVIDIA/AMD 四类芯片上，Mythos 仅用三天完成 AMD 移植并写了近 100% kernel，直接指向 CUDA 护城河的松动。产品侧，Google 发布 Gemini Decisions API 与 Decision 1 模型，按题打分而非逐 token 生成，输出 token 不收费；Runway 开源 27B 世界动作模型 Praxis-1，NVIDIA Cosmos 3 与 MBZUAI PAN 2 同周落地，世界模型赛道形成两条清晰路线。市场端 CoreWeave Q3 营收增 168% 带动半导体 ETF 涨 6.01%，A 股光模块与 PCB 集体涨停。

🔥 趋势洞察

  • 算力供应商可替换性上升：Anthropic 三天完成 AMD 移植、近全自动写 kernel，"compute multiplier" 概念把效率倍数摆上台面，硬件议价结构可能被重估
  • 世界模型双路线成型：NVIDIA Cosmos 3 走统一 omnimodal 主干，Runway Praxis-1 与 PAN 2 走视频预训练 + 小动作头，长程计划一致性是共同短板
  • Agent 工程进入复盘期：Amazon 受控实验显示多 agent 架构 token 耗 1.4–4.7 倍而增益多不显著，实现质量比架构选择更关键

📈 热点与趋势

  • Google 发布 Gemini Decisions API 与 Decision 1 模型 - 不做逐 token 生成文本，一次调用就能对最多 1000 道题打分，题型包括是非、最多 255 个选项的多选和 rubric 评分，输入可覆盖文本、图像、音频、视频与 PDF。定价为每百万输入 token 0.10 美元，输出 token 不收费，官方称比 Flash-Lite（轻量模型）便宜约 5 倍；Google 内部团队已用它做 Stitch Rapid 的产品流程设计 @sundarpichai（Google CEO）
  • Axios 独家：特朗普授权打击向中国转运 Nvidia 芯片的公司，商务部长阻拦 - 一名政府官员多次阻止执行，即商务部长 Howard Lutnick @axios（新闻媒体）
  • FT 独家：Eric Trump 支持的人形机器人公司与以色列国防军谈判 - 拟供应人形机器人巡逻加沙地下的哈马斯隧道，并可能参与作战 @FT（金融时报）
  • Google DeepMind 发布 AlphaGenome 2 - 在 AlphaGenome 1 基础上，预测不同细胞类型如何解读同一份 DNA，用于把基因变异定位到具体细胞层面的疾病成因 @sundarpichai（Google CEO）
  • LlamaIndex 转型文档 OCR 与应用研究 - CEO 称公司现在是文档处理领域的应用研究实验室，已自建 ParseBench、ExtractBench、ExtractBench Pro 三套评测，自训出 OCRia-1 模型，并在数据合成、算力训练管线、agent 调优上投入 @jerryjliu0（LlamaIndex CEO）

🔧 工具与产品

  • Runway 开源世界动作模型 Praxis-1 - 27B MoE 扩散 Transformer，同时预测视频与动作，Apache 2.0 权重。官方称在 NVIDIA RoboLab-120 榜上同时拿下世界动作模型第一与开源第一，完成同一机器人任务的成本比前沿 LLM agent 低 51 倍、速度快 15.6 倍。已上线 LeRobot 与 vLLM-Omni，vLLM-Omni 支持离线推理与 OpenPI/Positronic 服务，单张 H100 80GB 即可运行；NVIDIA 放出 NVFP4 checkpoint 与 Jetson 部署教程 @runwayml｜@AndyChenML（Runway 团队成员）｜@vllm_project｜@NVIDIARobotics
  • Speridlabs 开源 Iris-Z 图像模型 - 9B 与 32B 两个规格，在同一骨干中统一生成图像与深度估计，也能以深度为条件生成；官方称其深度估计超过 MoGe-3 等专用模型，权重、代码、demo 全部 Apache 2.0 @speridlabs（图像模型团队）
  • Plurai 上线 agent 仿真测试平台，免费开放 - 从用户代码重建 agent 与工具环境的数字孪生，生成模拟用户与任务，检查 agent 实际动作而非口头表述，每次失败附上复现 run 与可验证修复，并支持把线上失败回放压测新版本。已接入 Claude Code、OpenAI Codex CLI、GitHub Copilot @ilan_kadar（Plurai 创始人）
  • X 开源 For You 推荐算法 - 同时上线 Under The Hood 报告，用户可自查账号和帖子是否被标签限流，以及是否有政府要求或法律请求在特定国家限制触达 @Safety（X 安全账号）

⚙️ 技术实践

  • SGLang 公布两项推理系统优化 - megakernel 让 Muse Spark Open 在 8×GB300 上从 517 提升到 1109 tokens/s，解码每步内核启动次数从 1450 降到 97；另一项为混合模型做统一显存 arena，让全注意力 KV、滑窗 KV 与递归状态共用一块池，无分区参数、零跨类型碎片 @lmsysorg｜统一显存（SGLang 维护团队）
  • LeapQuant 让线性注意力的循环状态可量化到 4/8 比特 - 免训练方法，在 Qwen、Kimi、GLM 上精度对齐 FP32，线性注意力 kernel 快 4.25 倍，推理吞吐最高 2 倍，显存最多降 56% @conlesspan（LeapQuant 作者）
  • Unify AI 发布 Continual-ARC 基准 - OpenClaw、Hermes Agent、Prime Agent 三个 agent 都没能从经验中记住有效信息，也无法泛化到新任务；直接训练一个 9B 模型的权重则同时做到记忆与泛化 @DanielLenton1（Unify AI 创始人）
  • DeepSeek V4.1 Flash 在 4 张 DGX Spark 上开源跑通 - 单流 90 tok/s 对话、139 tok/s 代码，16 用户并发 368 tok/s，支持 1M 上下文与 10k tok/s 预填充，图像输入已上线 @Picomoorhead（Moor Insights & Strategy 分析师）
  • 论文：NVLink 上 MoE 推理的单边专家并行 All-to-All - 作者含 Li Bo、Anton Korzh、Noam Duvdevani 等，针对专家并行通信做单边语义改造 @DPZ（计算机论文推送账号）
  • vLLM 升级 EPD（编码-预填充-解码）分离 - 官方称相比 DeepInfer 的方案 TTFT 更低、单 GPU 吞吐更高（计入全部编码 GPU），已接入 vLLM Router、SMG 与 llm-d @vllm_project

Anthropic 路演视频首次系统披露算力策略：Claude 同时跑在 Trainium / TPU / NVIDIA / AMD 四类芯片上，Mythos 三天完成 AMD 移植、写了近 100% kernel ｜ CUDA 护城河被 AI 自身削平的现场证据

Tom Brown 提出「compute multiplier」概念——物理算力乘以可叠加的效率倍数，并明确指向递归自我改进：未来 Claude 自行发现倍数。最硬的证据是 AMD 迁移：原本需 6–12 个月、数十名工程师的加速器适配被压缩到 3 天、几乎无人工介入（口径为 MI355X 上的 prompt processing）。若数字成立，买方可在供给紧张的算力市场按性价比自由换供应商，直接冲击 NVIDIA 70%+ 硬件毛利——但需注意这是单方 investor presentation、无第三方复现。Simon Willison 用 MacWhisper 补出非官方 transcript，是稀缺一手材料。

来源：the-decoder.com ｜ simonwillison.net

NVIDIA Cosmos 3 系列 omnimodal world model：一个 mixture-of-transformers 同时处理并生成语言/图像/视频/音频/动作，开源 code + checkpoint + 数据集 ｜ 「统一 omnimodal backbone 是否成立」的关键一手材料

把 VLM、视频生成器、世界模拟器与 world-action model 收编进同一框架，摘要称理解与生成任务全面 SOTA：后训练模型被 Artificial Analysis 评为最佳开源 Text-to-Image 与 Image-to-Video，被 RoboArena 评为最佳 policy model；以 OpenMDW-1 在 Linux Foundation 下开源。对关注世界模型/具身智能主干选型的人，这是判断「单一 backbone 收编多模态任务」路线可行性的核心依据。

来源：hackernoon.com

MBZUAI IFM 开源 PAN 2：29B 稠密 MMDiT 世界模型，704×1248 / 24fps / 20 秒，Apache 2.0 放出权重与训练推理代码 ｜ 物理 AI「先仿真再执行」的开源基线

自报在 100 个多步任务上全计划完成率 34.0%，领先所测 6 个模型，但单步动作与人类偏好落后 MiniMax-H3，Physics-IQ 系统默认 37.48 vs 42.91，约三分之二的计划仍会漏步。与 Cosmos 3 对照读更有价值：一个是统一 omnimodal 大主干，一个是专注视频→动作的稠密扩散路线，两者失败模式（漏步率）都说明「长程计划一致性」仍是世界模型的主要短板。

来源：marktechpost.com

Runway Praxis-1：把 27B 视频基础模型改造成开放权重机器人 world model，预测未来画面同时输出动作，RoboLab-120 开源第一 ｜ 「用日常视频替代稀缺真机数据」的可扩展预训练路径

架构上是一个小 action expert 读取视频模型内部状态生成动作，在 DROID 上微调后真机 Franka 成功率与上一代 SOTA world action model 相当；放出 base/droid/yam 三套权重及 NVFP4 量化版本。与 GR00T 2、PAN 2、Cosmos 3 放在一起看，本周世界模型赛道已形成「人类视频预训练 + 小动作头」与「统一 omnimodal 主干」两条清晰技术路线，选型时值得按数据可得性与真机迁移成本权衡。

来源：paperswithcode.co

Meta Intelligent Delivery：把「每单位算力投到边际收益最高的请求」重构成两个 ML 问题，离线识别高价值请求 +20%，端到端再贡献约 10% 排序性能 ｜ 广告排序模型逼近 LLM 规模后的系统级优化底稿

核心是用 6B sparse + 20M dense 的 Resource Core Model 在召回前跑一次、全漏斗共享，再微调出预测 outcome / 算力消耗 / 延迟影响的专用模型，替代按 surface/context 粗分桶的规则策略。文中还讲了跨多阶段排序、数百模型、多代硬件的多层资源调度，以及用 agentic AI 持续检测并响应系统漂移。对做大规模推理服务与推荐系统的人，这是少见的「算力边际效用建模」完整架构披露，思路可迁移到任何异构硬件推理集群。

来源：engineering.fb.com

AWS 公开 SageMaker HyperPod 上的 silent data corruption 检测与恢复闭环：三道检查 + 节点 cordon 替换 + 从可疑窗口前 checkpoint 恢复，附完整代码仓库 ｜ GPU 算出「看起来合理但错误」的数时，ECC/Xid/DCGM 全都守不住

背景数字来自 Meta Llama 3 405B 的 54 天预训练：419 次意外中断里 6 次归因于 SDC。方案在 PyTorch DDP 循环里加非有限梯度检查、ring replay audit（让每张卡重算另一节点 micro-batch、逐 bit 比 loss 与梯度指纹）、权重指纹比对三道检查，命中后按 rank→K8s 节点名定位并 cordon。文章用一张表把 ECC / Xid / DCGM 深检 / NVLink checksum / checkpoint checksum 各自守的边界讲清楚，帮人建立「完整性检查分层」的 mental model；已在 32 张 H100 上做注入故障验证。

来源：aws.amazon.com

AWS 用 anti-unification 做形式化策略的语义 diff：过滤「重排合取项」这类语法噪声，只暴露 and 变 or 的真分歧，并配 SMT 反例解释 ｜ LLM autoformalization 多次采样无 ground truth 时的比对工具

在 e-graph 上声明代数律与领域规则，求两个策略的最具体公共模式，只展示一次共享结构、保留每处分歧；再配合 SMT solver 找出一满足一违反的具体赋值作为反例。核心场景是同一需求多次采样产出多个 SMT-LIB / Cedar / Dogwood / OpenShell policy / CEL 版本时，指出哪些部分稳定、哪些随采样漂移，优先 review 分歧处。作者把它定位为 semantic entropy 的形式化版本——不只给分数，而保留结构信息，对做 agent 安全策略与 autoformalization 的团队是可复用的方法论。

来源：aws.amazon.com
