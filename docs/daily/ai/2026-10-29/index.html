⚙️ 技术实践

  • LMSYS 与 AMD 在 MI355X 上训 SWE agent，SWE-bench 从 7.3% 提到 27.5% - 对象 Qwen3-30B-A3B，用 SGLang、Megatron-LM 与 Harbor 做全异步 agentic RL。RL 单步 850s 降到 284s，rollout 吞吐约 860→3,480 条轨迹/小时，同时跑 384 个 agent 沙箱。数字取自 100 题分层子集、每题 4 次尝试 @lmsysorg
  • Qwen 社区把 RISC-V CPU 塞进模型权重 - 开发者用 Qwen3.5-4B 的 Gated DeltaNet 状态当内存，在权重里实现 32 位 RISC-V CPU，模型可在前向中直接跑 C 与 MicroPython。DeepMind 数学集准确率从 48.6% 升到 100% @QwenDevs @divagr1925
  • NanoGPT Speedrun 纪录从 39.9 秒压到 6.7 秒 - 降幅 83.2%，超过 2025 年以来所有纪录降幅之和（81.4%）。做法是检索增强的 n-gram 提示，针对语料里高频重复、模型来不及记住的内容 @hermanbrunborg（NanoGPT Speedrun 参与者）
  • Amazon Trainium 把 Prime 360 的 diffusion 推理延迟降 40%+ - 用于生成电影级集锦镜头。Amazon 未披露芯片具体型号与吞吐 @AmazonScience（Amazon 研究团队）
  • NVIDIA 测 Cosmos 3 Super 的 serving 取舍 - Cosmos Labs 在 Nebius 上部署这一世界基础模型，比较延迟与吞吐两条曲线 @NVIDIARobotics
  • Replit 发布 ViBench 2.0 长周期软件构建基准 - agent 从空项目开始逐个功能构建产品，看不到下一个需求。GPT-6.1 Sol、GPT-6 Astra、Opus 5.5 也只有 49–65% 的构建能通过全部检查。已纳入 Fireworks 的 Specialized Intelligence Index @Replit

Meta Andromeda：把 LLM 式 MoE 引入广告召回，1/300 推理 FLOPs 下逼近排序级效果 ｜ 召回阶段的模型-系统-GPU 三层协同

用户侧从单塔改为多个专家用户塔（融合序列行为、用户群表征、LLM 语义特征、跨场景共参与信号），候选广告塔做联合编码注入实时上下文，交互层用 MoE attention gating 动态路由到最相关用户专家。配合 GPU 协同设计，吞吐达每秒超 10 亿广告（较 2024 版提升 100x），Facebook 转化率提升 2.4%。文中还点出十亿级吞吐下内存带宽与 CPU-GPU 传输成为新瓶颈，需把碎片化分布式负载统一进单 GPU 流水线。对做大规模召回/排序的从业者是难得的模型-系统-硬件三层协同一手样本，注意方案强绑定 Meta 自研栈、外部可迁移性有限。

AWS 给出 Bedrock AgentCore 上的企业级 Agentic AI 平台参考实现：推理与工具走双网关，五类边界证据作发布门禁 ｜ 可直接抄的 AgentOps 治理架构

核心观点：Agent 上生产的瓶颈不在模型和工具调用，而在其周边——多团队如何在安全边界内自建、谁拥有模型与工具、AgentOps 与错误处理如何不越界、财务如何跨账号看成本与健康度。方案分四个平面（开发者体验、平台控制、Workstream 执行、保障与运营），以 Workstream cell 为扩展单元，强制所有推理走审批网关（含 guardrails、区域/模型白名单、per-team 限流与 token 配额）、工具走认证 MCP 网关（最小权限、可审计 owner），并给出模型访问、工具访问、身份、发布回滚、退役清理五类边界证据作为发布门禁。配套 GitHub blueprint 可直接部署验证。

Google Agents CLI 的 eval 闭环 walkthrough：generate → grade → compare → analyze → optimize 一条命令链爬山 ｜ agent 回归测试可直接照抄的命令清单

从 LangChain 模板脚手架起步，把默认单条用例扩成 4 条探测不同行为的用例，展示 baseline 均分 4.0、stdev 1.41 的解读方式，再逐步演示回归检测、换模型后端实验、定时调度与告警。`eval grade` 用 LLM-as-judge 打分、`eval analyze` 聚类失败主题、`eval optimize` 自动对 prompt 做爬山优化。对正在给 agent 搭回归测试的团队，这是今天最可直接落地的一条工程内容；代价是绑定 Google Agents CLI 生态。
