📊 今日概览

今日最重磅的是 Google 发布 Genie 4 交互式世界模型，以 Gemini 作"大脑"支持自然语言实时改变天气、移动镜头，自带环境音与可对话人物，先向受信测试者开放后进入 AI Ultra。资本层面，NVIDIA 向 Meta 975 亿美元基础设施融资投入 30 亿股权、AMD 追加 10 亿，芯片供应商从卖方变股东；Modal 年化收入破 10 亿美元并完成 7.5 亿美元 D 轮。模型侧，Liquid AI 发布 LFM3 家族六个端侧模型，1.7B 底座在浏览器 Agent 基准反超 9B 模型；Anthropic 自述内部研究模型自主发现核心算法，消耗 1400 万 token 无人类输入。此外 Ai2 的 NoveltyBench 揭示 LLM judge 判断新颖性准确率波动超 50 个百分点，为"别信 judge"再添实证。

🔥 趋势洞察

  • 世界模型走向交互化：Google Genie 4 用 Gemini 把自然语言指令翻成动作、规划多步事件，SpAItial Echo-3 手机视频直出米级 3D 场景，世界模型从"生成"转向"可操控"
  • 芯片供应商变股东：NVIDIA 30 亿、AMD 10 亿入股 Meta 975 亿融资，供应商用股权绑定超大规模客户算力部署，算力供应链结构反转
  • Agent 评测与数据工程成焦点：Ai2 NoveltyBench 揭示 judge 脆弱性、Property Finder 发现 96.8% 循环评测标签，Apple 与蚂蚁分别提出工具使用 agent 的数据缩放律与轨迹构造范式

🔧 工具与产品

  • Liquid AI 发布 LFM3 家族，6 个模型全部端侧可跑 - 三混合（tri-hybrid）新架构，覆盖文本、视觉、音频、omni 与决策模型。LFM3-1.7B 支持 256k 上下文；VL-2B 支持视频输入；Audio-2B 支持 18 种语言语音对话；d1 系列单次前向输出带类型的预测与校准概率。官方称 1.9B 的 VL 版对标 Gemma 4 12B、Gemini 3.5 Flash Lite 与 GPT-5.6 Luna，单卡即可微调，架构针对 GPU / CPU / NPU 共 14 类处理器优化 @liquidai（Liquid AI，MIT 孵化的端侧模型公司）
  • SpAItial 发布世界模型 Echo-3，手机视频直出米级 3D 场景 - 输出 3DGS 表示，覆盖单间房、多层建筑与户外公共空间，可对重建结果做风格化改写。产品今日已上线 App @SpAItial_AI（SpAItial AI，3D 世界模型创业公司）演示
  • OpenDuet 开源：可自托管的主动式 agent 模板 - 兼容任意 agent harness，内置素材生成与编辑、human-in-the-loop 审批、computer use，覆盖移动端、Web 与消息渠道，基于 CopilotKit 与 AG-UI，可直接克隆改造成企业版 @ataiiam（Atai Barkai，CopilotKit 团队开发者）
  • Weaviate Query Agent 加 effort 参数，按查询难度分配算力 - 每个请求可选 `medium` / `high` / `ultrahigh`，控制初始检索之后的重排与精炼强度。BRIGHT Biology 上召回率分别为约 43%、50%、57%。agent 读 schema 后会把"70 美元以下的复古鞋"拆成硬价格过滤加语义检索 @weaviate_io（Weaviate，向量数据库公司）

⚙️ 技术实践

  • Sasha Rush 用 Lean 验证 Rust tokenizer 流水线 - 出发点是 RL 训练与推理的 tokenizer 不一致会毁掉整轮训练，而消息拼装目前还靠 Jinja 模板。他把 agent 流水线的关键部分做成 Lean 可验证的 Rust 原型 @srush_nlp（Sasha Rush，Cornell 教授 / Hugging Face 研究员）
  • InfiX.ai 的 miniTE 在 8×B300 上把学习器更新提速 1.33–1.37 倍 - 低精度训练框架，针对 NVFP4 计算减少训练-采样不一致：诊断量化到 token 概率的偏差、用 TRIAGE 拦住高风险更新、用 grouped GEMM、连续 buffer 与算子融合压低开销 @lmsysorg（LMSYS Org，SGLang 出品方）
  • 700 肌肉人形机器人训练从 2 天缩到 4 小时 - 三年前用 CPU 模拟器加 SAC 训练单个行走动作要 2 天；现在用 SuperMimic 加 MJWarp，单张 RTX 5090 四小时可学会跟踪 1.5 小时动捕数据 @KaiboHe（Kaibo He，机器人学习研究者）
  • Ray-Ban Meta 眼镜 + Opus 5.5 改造成赛道实时教练 - 眼镜以 30 帧/秒把画面传到手机，视觉模型逐帧找路面、路肩与下一个弯，Opus 5.5 规划外-内-外的走线并画在路面上；绿全油、红刹车、橙弯中，附刹车距离倒计时与反打方向提示。全部本地推理，丢路面时线条淡出而非给错提示。同一节圈速从 1:52.4 提升到 1:47.1 @N01ennn（AI 内容博主）
  • Oracle 把 NVIDIA Vera Rubin NVL72 与 Vera CPU 引入 OCI - 用 Acceleron RoCE 把 GPU 机架连成集群，覆盖训练、推理与 agent 执行；Vera CPU 定位加速工具调用、承载并发 agent 负载 @OracleCloud（Oracle Cloud 官方账号）

NVIDIA 向 Meta 975 亿美元基础设施融资投入 30 亿股权，AMD 追加 10 亿——芯片供应商从卖方变股东 ｜ 算力供应链的结构反转

Meta 这轮 975 亿美元融资中，NVIDIA 出 30 亿、AMD 出 10 亿，芯片厂商合计持股 40 亿（Meta 此前称最多 50 亿来自 NVIDIA/AMD/Broadcom）。核心信号是芯片厂商不再满足于卖硬件，而是用股权绑定超大规模客户的算力部署；NVIDIA 明确押注消费级 AI Agent（Meta Muse 家族）的持续推理负载将成为 2030 年代主导算力需求，Vera Rubin NVL72 机架是承接这一支出的硬件代际。文章还点出黄仁勋与扎克伯格在 AI 政策游说上的立场张力。谈资价值在于：这是"供应商变股东"这一结构性反转的第一个大额样本。

来源：techtimes.com

Anthropic 平台团队访谈（两篇互补）：把模型"大脑"与 agent"执行手"解耦，用 Rust 重写 Messages API ｜ 一线厂商的 agent runtime 架构取舍

Latent Space 两篇访谈拼出 Claude Platform 的工程全貌。架构侧：Managed Agents 把 session log 与 harness 同执行代码的 sandbox 解耦，sandbox 按需创建、失败不拖垮整个会话，凭据由代理单独持有、不进入 sandbox，同时改善延迟、可靠性与安全隔离；"Dreaming"只是用一个 agent 检视另一个 agent 的产出并写回记忆，是同一套原语上的上层行为。发布侧：模型发布同时是 API 发布（如跨轮保留 thinking block 以防推理被蒸馏提取，但会破坏客户既有 harness），早期访问计划的价值在于客户在自家 harness 中跑评测、暴露 Anthropic 产品覆盖不到的行为。对任何设计 agent runtime 的人，可直接对照自问：哪些部分必须存活、哪些执行不可信代码、哪些密钥真正需要出现在代码运行处。

来源：latent.space（平台团队访谈） ｜ latent.space（Opus 5.5 工程决策）

Ai2 发布 NoveltyBench：prompt 改几个词，LLM judge 判断研究想法新颖性的准确率波动超 50 个百分点 ｜ "别信 judge"的实证

Ai2 用 ICLR 2026 同行评审中明确讨论原创性的段落，构建高/低新颖性 idea 池（154 vs 145 条），系统测试 6 个 LLM judge（GPT-5.1/5.2/5.4、Claude Sonnet 4.5、Opus 4.5/4.6）。三个反直觉结论：prompt 改几个词即可让二选一准确率波动超 50 个百分点；检索增强与更多推理并不稳定提升判断；两个专门构建的新颖性评估系统反而不如朴素 prompt 的 Claude Opus 4.6 基线。附带开源 benchmark、数据集与自动化构建 pipeline。对做 LLM-as-judge、科研 Agent、自动评审系统的人，这是一份可直接引用的"judge 脆弱性"证据。

来源：huggingface.co

Property Finder 在 Bedrock 上发现评测集 96.8% 标签继承自现任 VLM 预测，纠偏后准确率提升且降本 86% ｜ 循环评测的完整踩坑样本

把视觉 AI 迁移到 Bedrock 时发现：评测集 96.8% 的标签直接继承自现有 VLM 的预测而非人工核验，形成循环评测——任何替代模型都被判为"不如现任"。纠偏流程完整可照搬：领域专家在无模型输出参考下重新标注 356 张 UAE 图片（256 开发 + 100 评测），再用 Micro F1 驱动进化式 prompt 优化从 v0 迭代到 v27，最终准确率提升同时降本 86%。还披露了隐藏错误类型：水印文本字符级幻觉、多房型被强制单标签、标注者引入规格外类别。任何做模型选型/评测集建设的团队都该读。

来源：aws.amazon.com

Liquid AI 发布 LFM3 系列：1.7B 共享底座派生 6 个专用多模态模型，浏览器 Agent 基准反超 9B 模型 ｜ 端侧小模型的窄任务反超样本

六个模型共享 1.7B 参数底座（含文本/视觉/语音/结构化决策版本），主打单卡可微调、端侧或私有服务器部署。架构是 tri-hybrid（卷积 + 局部/全局注意力），22T token 预训练。厂商自报数据：1.7B 文本模型在 WebArena-Verified（38.42 vs Qwen3.5-9B 28.94）和 AutomationBench（41.29 vs 15.10）上反超更大模型，BFCL V4 函数调用 71.39 领先；但 MCP-Atlas、SWE-bench、GPQA、RULER 128K 均落后，官方文档直言不推荐用于 agentic coding 与复杂多步推理。托管 API 定价 $0.08/$0.20 每百万 token，缓存输入 $0.02。适合做浏览器自动化/表单操作类窄工作流的团队做小规模试点，但需自行验证失败重试与升级路径。

来源：venturebeat.com ｜ huggingface.co

Coroot 把 KServe / NVIDIA Dynamo / Ray Serve / Kthena / llm-d 五个推理框架放同一集群实测，梳理"框架→K8s 原生对象"映射 ｜ 自建推理栈的名词对照表

文章逐一拆解每个框架如何把"一个模型部署"翻译成 K8s 原生对象：KServe 走 Deployment/Knative Service；Dynamo 展开为 frontend/prefill/decode 多 Deployment，流量走 TCP request plane + NIXL + NATS；Ray Serve 直接管 Pod 并蓝绿升级；Kthena 用 Volcano gang-scheduling；llm-d 借 LeaderWorkerSet 的 DisaggregatedSet。同时点出监控工具面对这些动态命名资源与长尾延迟 SLO 的困境。对自建推理栈的人是一份有用的横向对照，注意是 Coroot 自家可观测性产品的工程博客视角。

来源：coroot.com

Oracle 与 Google 宣布 2027 年起在 OCI 提供 TPU，成为 Google 之外首个卖 TPU 的超大规模云 ｜ 云厂商从"只卖 GPU"转向多芯片组合

覆盖训练、生产推理与 agentic AI 负载，支持 dense 与 MoE 模型、长上下文与推理场景，并首次点名 TPU 8t（训练）/TPU 8i（推理）双架构。战略含义是企业可按成本/吞吐/能效在 GPU 与 TPU 之间选型，云厂商供给从单一芯片转向组合。但全文无价格、无容量规模、无互联规格，属公告级信息，适合作为算力格局变化的索引条目而非深度阅读。

帝国理工孵化公司 Machenta 完成 4000 万美元种子轮，用"单次人类演示"替代语言指令做 VLA ｜ 站在 VLA 语言范式对立面的路线

Creandum 与 USV 联合领投，号称英国机器人初创最大种子轮。核心技术是 vision-demo-action 模型：输入相机图像 + 单次人类演示，闭环预测动作，完全在仿真中预训练，真实数据仅用于部署时那一次演示。自报压力测试在六种机器人上完成 74/74 积木放置、78/78 螺丝刀交接、97/99 立瓶。值得读的点在于它明确站在 VLA 语言指令范式的对立面（演示替代语言），并给出与 Physical Intelligence（$11B）、Skild AI（$14B）、Generalist AI（$2B）的估值与路线对比——但任务简单、人形结果初步、无第三方基准，需批判性看待。

来源：en.wowtale.net

Meta Python Typing Survey 2026：认为"类型让 AI 生成代码更可靠"的比例从 18.5% 升至 38.4%，同时暴露 agent 刷 #type: ignore 的负面模式 ｜ Coding Agent 与类型系统的交互数据

第三届调查（1794 份回复）中 AI 与类型检查器的交互成为新看点：42.5% 受访者让 AI 写类型注解，24.4% 的 AI 编码工具会主动调用 checker 并修错（该群体中 61.6% 还用 AI 修类型错误）。负面模式值得警惕：AI 偷懒用 object 兜底、agent 到处刷 #type: ignore 压制报错。第三方库类型缺失仍是头号痛点（65.1%），Django/SQLAlchemy/Pydantic/NumPy/pandas 被点名。对做 Coding Agent 与代码质量工具的人有直接参考价值。
