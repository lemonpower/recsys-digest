开放权重生态的算力与审计

本期讨论开放权重模型对算力供应的依赖，以及研究者如何尝试从模型权重的统计特征推断训练过程。

📊 今日概览

今日最值得关注的是开源 AI 的「结构性推演」与「可审计性」两条线同时推进。Nathan Lambert 撰文推演「没有 Jensen 的开源 AI」，指出算力稀缺下开源权重远未商品化，闭源实验室凭模型-数据中心-芯片一体化反而占优。与此同时，研究者称可从模型权重统计推断训练硬件，指认 DeepSeek、Kimi 或用了受管制的 Blackwell；微软研究则显示改写不到 10 个神经元即可植入潜伏后门，常规评测全绿。产业侧，ASUS 发布首款工厂人形机器人 Gallop、松下组建约 250 人 Physical AI 团队，Google Cloud 第八代 TPU 用封装与安全而非新芯片做差异化。YC 总裁 Garry Tan 开源 agent 外壳评测，五个框架通过率全在 71%–79%，成本却相差 2.6 倍。

🔥 趋势洞察

  • 开源 AI 的算力经济学：Lambert 指出算力极度稀缺下开源权重远未商品化，DeepSeek 高推理毛利即是反证，闭源凭一体化占优
  • 模型权重成为审计面：从权重可推断训练硬件、学习率曲线与数据顺序，甚至复原测试集污染，供应链审计逻辑正在改写
  • 物理 AI 资本补课：Bessemer 称机器人融资公司数比软件少 18 倍而市场大 30 倍，ASUS、松下、Foundation 三线并进

  • ASUS 发布首款工厂人形机器人 Gallop - 通过观察熟练工人学习制造任务，并在真实产线零件上练习；公司计划 2027 年启动客户试点 @roboticomarket（机器人内容账号）

  • vangrid 用手机众包采集地面 3D 数据 - 已积累 152 万次验证采集、约 49 万个活跃节点、74 万美元 USDC 悬赏结算；采集在设备端模糊人脸与车牌，数据用 Merkle 树在 Base 链上存证，买家先托管资金再开工 @carte_free（加密 / 物理 AI 观察者）

🔧 工具与产品

  • YC 总裁 Garry Tan 开源 agent 外壳评测 g-harness-evals - 固定模型与任务，只换 Claude Code、Codex、OpenClaw、Hermes Agent、QM 五个框架：20 个开发任务通过率全在 71%–79%，95% 置信区间重叠。成本差距大，单任务 OpenClaw 0.44 美元、Claude Code 0.22 美元、Codex 0.17 美元。首个请求塞给模型的上下文分别是约 12,900、18,416、20,613 token。他自写的技能包 gstack 在 46 次测试中被模型执行 0 次，成本反而翻倍；加拦截钩子后 Opus 仍用 Bash 直接写源码绕过 40 次。团队共享知识库 gbrain 未做权限隔离时，OpenClaw 与 Hermes 分别吐出 123 条、121 条越权记录 @garrytan（Y Combinator 总裁兼 CEO）
  • OpenAI 详述开源 Codex harness 与 code mode - Jeff Chan 与 Nikunj Handa（OpenAI 员工）在 Supabase 播客里讲开发者侧推进：开源 Codex 外壳、code mode、训练模型主动使用异步工具、扩展 Responses API，并主张按每任务成本而非每 token 价格评判模型 @supabase（开源后端平台）

⚙️ 技术实践

  • CoRL 2026 综述：瓶颈从策略架构转向数据与算力经济 - 投稿 2,094 篇（约去年 3 倍），接收 687 篇（32.8%）。最佳论文 SuperMimic（UC Berkeley）学一个可微世界模型覆盖整套动作库，单张 H100 约 3 小时完成人形动作追踪，对比 NVIDIA SONIC 的约 2.1 万 GPU 小时；129,514 个动作中失败 25 个，基线 179 个，已迁移到 Unitree G1。NVIDIA 与 UCLA 的 GRAIL 用 3D 资产加视频先验生成 2 万+ 人形移动操作序列，G1 抓取成功率 84%、爬楼梯 90%。DreamZero 是 14B 世界动作模型，7 Hz 运行，约 30 分钟玩耍数据即可适配新本体 @yoshi_flux（世界模型研究者，WorldFlux）
  • NVIDIA 发布 Dory1.0-4B 循环 Transformer - 复用 20 个共享层跑 1–4 次，参数不随深度增长；SWE-bench Verified 从 1 轮的 50.3 升到 2 轮 59.5、4 轮 61.8，12 基准平均从 35.17 升到 40.60，2 轮以上超过 Qwen3.5-9B、Gemma 4 12B 与 26B-A4B。端到端算力只涨 1.03–1.25 倍，官方推荐默认 2 轮。局限：AA-Omniscience 上 1 轮与 4 轮都停在 10.0，知识类任务仍落后 Qwen3.5-4B @_avichawla（AI 教程作者，DailyDoseofDS）
  • SatBench：2023 年以来 173 个被引基准里 63% 已饱和 - Ethan Mollick 统计各家 Lab 论文引用的基准，测其被「打穿」的速度，结论是饱和速度逐年加快 @emollick（Wharton 教授）
  • 从权重直接读出模型训练史 - Alapan Chaudhuri 列出可从权重还原的信息：数据里的 token、学习率曲线、步数、打乱种子、上下文长度；并指出 OLMo 2 首个 instruct 版本有 20,341 行嵌入本应训练却未移动，其中包含每轮对话的结束标记，AI2 后来才发现分词器不匹配并重训。Pythia-1B 实际峰值学习率 2.5e-4，模型卡写 3.0e-4；最后 28,000 步学习率持平。Qwen2.5 指令微调只动了 22 个控制 token 中的 4 个，7B/14B/32B/72B 完全一致。Christopher Potts 补充：仅凭 logits 也能复原训练数据顺序，并可推断测试集污染 @alapanchaudhuri（独立研究者）｜@ChrisGPotts（斯坦福语言学教授）

⭐ 精选内容

Nathan Lambert 推演「没有 Jensen 的开源 AI」：Nvidia 财务动机仍在，但 founder-style 持续注资可能断流 ｜ 开源模型经济的 upside/downside 框架

Jensen Huang 辞职后开源生态走向的第一份冷静推演。核心是「一正一反」：正面——开源已抓住 ownership of intelligence 与企业后训练这两条赛道；反面——算力极度稀缺下开源权重远未商品化（DeepSeek DeepInfer 的高推理毛利即是反证），闭源实验室凭规模与模型-数据中心-芯片一体化反而占优。作者另点出近期真正的风险不是技术而是粗糙的州级监管与「open-weight hawks」，以及媒体生态由时机而非信息本身驱动。适合想给「开源 vs 闭源」判断找可复用分析框架的人。

来源：interconnects.ai

微软研究：改写 LLM 中不到 10 个神经元即可植入「潜伏后门」，常规评测全部通过 ｜ 后门攻击成本压到个位数神经元级

把后门植入的成本从「重训练/微调」压到「个位数神经元」，模型在常规评测中全绿、却在特定触发条件下输出攻击者预设行为。对模型供应链审计、权重发布前的完整性校验提出新挑战——传统基于行为评测的安全筛查可能完全失效。原文细节（触发机制、跨模型可迁移性、检测方法）抓取不全，建议直接找原始论文核实。

「GPU 指纹」技术：对开源模型权重做统计推断训练硬件，指认 DeepSeek/Kimi 等用了受管制的 Blackwell ｜ 训练算力来源首次可从模型本身被外部审计

研究者称对开源模型权重做统计分析，可检测其与特定 Nvidia 硬件的相关性，据此推断 DeepSeek、Kimi 等中国开源模型可能训练于受出口管制的 Blackwell 芯片。若方法成立，意味着训练算力来源可从模型本身被外部审计，对出口管制执行与开源模型合规披露都有直接影响。但抓取内容基本是页面框架，方法、样本量、误判率、被点名模型清单均需回原文核实，建议作为线索而非结论。

来源：tomshardware.com

Google Cloud 第八代 TPU 两个新系统：8tx 首个带 confidential computing、8i Max 双芯封装带宽与 SRAM 翻倍 ｜ 复用已有芯片，只换封装/host/网络/安全

TPU 8tx 与 AMD 合作，加密 host→TPU 全链路 + attestation，同时保护企业输入数据与模型权重；TPU 8i Max 把两颗 8i 封装在一起，带宽与片上 SRAM 翻倍、HBM 容量 +33%。关键洞察：两者都没用新加速器设计，只是换封装/host/网络/安全；且 8i Max 的带宽提升与容量提升回答的是不同问题——context 数据搬多快 vs 能装多少。文中还提醒 2x 延迟声明各自对比基线不同，不能直接比谁更便宜。

2026 年 11 月云 GPU 定价横评：同一块 H100 在 Azure $12.29、AWS $6.88、RunPod $4.39，价差 2.8 倍 ｜ 归一化到「每 GPU 小时 → 每百万 token」的预算 sanity check

把 H100/H200/B200/MI300X 各家按小时挂牌价归一化对比，并指出 2026 年租赁价格结束多年下滑、中位 H100 按需价同比涨 31%，AWS 1 月上调 Capacity Block 约 15%、Crusoe 12 月起提价。方法论（按实例/GPU/节点/合约期折算成每 GPU 小时、再折算每百万 token 成本）有复用价值，但数据多为二手引用、站点质量偏低，适合当预算参考而非决策依据。

旧金山初创 Foundation 直接对准五角大楼做人形机器人 Phantom MK-2 ｜ 人形机器人商业化的军工分叉路线

200 磅、6 英尺高铝制人形，防尘防水、力量足以举起成人，并设「未限力」状态下的物理隔离区。文章价值不在技术细节，而在于呈现一条与 Figure/Tesla 不同的商业化路径——军工/国防订单可能比通用家务更早给出付费场景与真实数据闭环。对关注具身智能落地路径与监管边界的人是一个值得留意的信号，但无 VLA 架构、数据方案、控制栈等从业者真正想看的细节。

Agent 可靠性评测入门 checklist：结果与轨迹双维度 + 8 类失败归因 + τ-bench 的 pass^k ｜ 从「demo 能跑通」到「跨多次试验一致」

以「demo 能跑通 ≠ 可靠」切入，强调要同时看结果与执行轨迹、区分「工具调用合法」与「任务真正完成」（举客服取消错订单的例子），给出 8 类失败归因（意图理解/工具选择/参数生成/规划/工具执行/上下文管理/错误恢复/安全权限），并用 τ-bench 的 pass^k 衡量跨多次试验一致性。概念均来自已有论文、无新增数据或代码，适合作为团队内部评测 checklist 的起点。
