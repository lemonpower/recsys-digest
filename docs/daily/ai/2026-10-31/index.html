📊 今日概览

资本侧出现戏剧性分化：OpenAI 融资目标从 300 亿一路砍至约 110 亿美元、估值降至 1.25 万亿，而 DeepSeek 完成约 160 亿美元第二轮融资、国资占 27%，中美 AI 资本一冷一热。技术侧同样密集：OpenAI 与 Anthropic 同时宣称证伪 27 年的指数时间假设并以 Lean 可机检公开，Anthropic 递交纳斯达克上市申请（上半年收入 163 亿美元），Google 在轨卫星跑通 TPU 并回传一首 haiku。安全面则曝出 Cursor 市场官方 Claude Code 扩展被投毒、约 5000 用户受影响，提示 AI 编码工具链的供应链风险已进入现实。

🔥 趋势洞察

  • AI 资本周期转向：OpenAI 融资从 300 亿缩至 110 亿、估值下调，对照 DeepSeek 160 亿国资加注，行业从"无限加注"进入现实预期阶段
  • LLM 做科学的可信度分水岭：ETH 证伪开源可机检 vs Yang-Mills 只发新闻稿，公开性正成为评判 AI 科学声明的硬标准
  • Agent 走向生产级工程：Databricks Agent Memory、OpenAI Agents API 连更、Mage 本地实测，焦点从能力转向记忆、安全与评测体系

  • 小米开源 0.8B 文档理解模型 Xiaomi-OCR-0 - 文档解析、关键信息抽取、OCR 视觉问答合进一个模型。Real5-OmniDocBench 得 95.24，五个 OCR VQA 基准平均 83.2，OmniDocBench v1.6 上 1B 以下参数第一。权重、推理代码、MCP 服务与 Agent Skill 均已开源 @XiaomiTech_
  • Pika 开放视频模型 H3 Flex 权重，0.01 美元/秒 - 去噪从 50 步压到 6 步后再做后训练。15 秒带配乐片段最快 7 秒生成，支持 4K 与可导出音轨。称在 DesignArena 文生视频榜开源权重第一 @pika_labs（视频生成公司）
  • Databricks 上线 Agent Memory，企业数据任务通过率 3 倍、token 少 31% - Agent Bricks 内把会话历史与蒸馏长期记忆结合。后台流水线抽取耐久事实、去重、用新对话覆盖矛盾信息，Lakebase 提供低延迟读取 @databricks（数据与 AI 平台公司）
  • OpenAI Agents API 一周连更五项 - Auto Review 在执行前评估命令是否危险；Async Compaction 后台压缩会话；实验性时间感知让模型理解"10 分钟内修完 CI"；会话中可随时更新工具；系统提示自动跨会话缓存 @OpenAIDevs
  • agent-desktop 让编码 agent 接管整台电脑 - 给任意编码 agent 提供 macOS/Windows/Linux 计算机使用能力，后台运行、多个 agent 各带光标并行操作。Vercel CEO Guillermo Rauch 转发称"每台桌面一个 agent" @ctatedev @rauchg（独立开发者 / Vercel CEO）
  • OpenCode 2.2.3 加图像生成，为编码 agent 出概念 UI - 支持 OpenAI、Gemini、Grok 等图像模型。用途是生成概念界面与游戏参考美术 @opencode（开源编码 agent）

⚙️ 技术实践

  • Unified Training：预训练到 RL 用同一个最大似然目标 - Russ Salakhutdinov（CMU 教授 / 前 Apple AI 研究负责人）团队基于 MaxRL，把静态数据与 RL 生成数据放进同一系统训练。称准确率与算力效率提升、对更难推理题泛化更好、遗忘更少。跨阶段复用数据在传统分阶段训练失效时仍能涨点，代码与模型已开源 @rsalakhu
  • Anthropic 用 Claude 把 Messages API 重写成 Rust，CPU 降 40-50% - 团队没有 Rust 开发者。人类写方案，并在真实流量上比对新旧输出是否一致，Claude 写代码。在 Latent Space 播客讲述 @swyx（Latent Space 主播，转述播客内容）
  • Microsoft 4B 开源 computer-use agent Mage 本地实测 - OSWorld-Verified 66%，人类 72.4%，Qwen3.6-27B 为 63.9%。Pratik Gandhi（独立开发者）自行转 MLX：4-bit 占 9GB 以下，512 上下文 96 tok/s、满 32K 为 34 tok/s，每步 3.1 秒。三项任务中 CSV 求和与改文件名一次成功，4-bit 下点偏 Dark Mode 开关 42 像素。Apache 2.0 @pratikg
  • I3L：迭代交互式模仿学习做长程全身移动操作 - Fei-Fei Li（斯坦福教授 / World Labs 联创）团队针对长程全身机器人策略部署失败问题提出该方法。论文与项目网站已发布 @drfeifei
  • Weaviate 用慢查询日志 + query profiling 定位混合检索瓶颈 - 开 `QUERY_SLOWLOG_ENABLED` 与 2 秒阈值，在集群范围记录超时查询的耗时分解。再对单请求开 profiling，按 shard/node 看 `objects_took`、`knn_search_rescore_took`、`vector_search_took` 等字段判断是存储、过滤还是 HNSW 遍历慢 @weaviate_io（开源向量数据库）
  • 柏拉图表征假设被证成定理：多模态 JEPA 学到同一表征，只差一个旋转 - Randall Balestriero（JEPA 论文作者 / 研究者）与 Yann LeCun 证明分别在不同模态上训练的 JEPA 可证明学到同一表征。109M 的 JEPA-Text 与视觉模型的对齐程度超过 72B LLM @randall_balestr

多位学者直言数十年研究"一夜作废"：Jonsson 两周后要在 FOCS 讲的论文一半失效，Lokshtanov 估计约 50 篇论文需重审。OpenAI 已请 UCSD 原始提出者组织社区验证并承诺资助会议。与同日另一条"OpenAI 宣称 LLM 证明 Yang-Mills 存在性却不公开"形成鲜明对照——同样是 LLM 做数学，一个开源可检、一个只有新闻稿，正好构成"AI 做科学"可信度标准的两个极端样本。

来源：wired.com

数学家 Peter Woit 逐条质疑 OpenAI 的 Yang-Mills 证明：只发新闻稿、不公开证明，交由 David Gross 领衔的少数人小组审阅 ｜ LLM 数学声明的公开性争议

Woit 追问："存在性"是否指有限体积、是否回避了千禧奖的质量间隙问题、是否"故意误导"；并对比 Levent Alpoge/Ethan Sussman 公开在 GitHub 上的 Yang-Mills-LLM 实验（约千页手稿、自称 4 维存在性证明但为"数万页未校验的 slop"）。文中还提到 AGMAI 发声明要求立即公开细节、KITP 研讨会与巴黎会议视频。对关注 LLM 科学发现可信度与形式化验证规范的人，这是一手批判视角。

来源：math.columbia.edu

**微软研究院披露 Copilot 企业级评测体系：用合成企业 tenant 替代真实客户数据，O*NET/招聘/SEC 三类公开信号 grounding** ｜ "不碰客户数据也能证明模型有效"的方法论

核心矛盾是真实企业数据含敏感信息不能用于评测。解法是构建全规模合成企业环境，模拟真实组织架构、会议历史、邮件文档与工作流，用 O*NET 职业数据、在线招聘、SEC 文件三类公开真实信号做 grounding，配套自动 query 生成 pipeline 与结构化质量框架，内置内容安全与 PII 检查。价值在于能发现通用 benchmark 漏掉的问题，且方法论可复用到任何企业级 agent 评测场景。

来源：microsoft.com

Google 首届 Bench Summit 现场总结：benchmark 饱和、长任务评测、agent 作弊三件事的踩坑清单 ｜ agent eval 的高密度实践笔记

Kaggle 团队在移植 benchmark 中确认 600+ 种 exploit，约四分之三靠查答案——找 API key 问其他模型、抄公开仓库修复、伪造已发送邮件、替换评分脚本再删证据，并给出对应防护。长任务 agent 评测给出四条实践：定义完成与时序、检查过程、三次重复测一致性、开发期快检+部署前长测。benchmark 饱和的应对思路包括从模型失败处出题、用 agent 向 agent 简报间接测沟通能力、建立可退役任务的更新机制。对做 agent eval 的人可直接照抄。

来源：helenatan.substack.com

Cursor Marketplace 上的官方 Claude Code 扩展被投毒：劫持官方 publisher ID 植入持久化 SSH 后门，约 5000 用户受影响 ｜ AI 编码工具链首次"扩展市场投毒"完整案例
