⭐ 精选内容

NVIDIA 把 agent 安全运行时 OpenShell 捐给 CNCF，并参与 Google 主导的 Agent Substrate ｜ K8s 上跑长驻 agent 的运行时底座开始成型

OpenShell 以 Sandbox 项目身份进入 CNCF，提供 deterministic controls 一类的 agent 运行时约束；Agent Substrate 则在 Kubernetes 上保留 agent 环境、空闲时释放算力、跨共享池 suspend/resume，直接针对「长跑 agent 白占 GPU」这一成本痛点。同批发布 DSX AI Factory 三件套：NVKE 管 GPU 集群生命周期、NVKR 做签名版本锁定镜像、Snapshot 用秒级 checkpoint 副本加速推理扩容。对做 agent 工程与推理部署的人，这是一份「治理 + 调度 + 扩容」的完整开源栈底稿，且 OpenShell 与 Agent Substrate 集成意味着跨云跨本地统一管控 agent 的路径开始收敛。

来源：blogs.nvidia.com

Meta 开源 TLX：在 Triton 之上补出 Hopper/Blackwell 时代缺失的「执行编排」层 ｜ GPU 编程模型演进的中间层叙事

TLX（Triton Low-Level Extensions）保留 Triton 的高生产力编程模型，补上显式 warp-group 与 cluster 级调度、TMA 异步搬运、TMEM 分配、paired-CTA 协作。文章的核心论点是 SIMT/SIMB 粒度都不够用——现代 FlashAttention/GEMM kernel 的性能取决于多个执行 agent 如何协作，而 Triton 把这些关系藏在编译器后面，形成「编译器追赶硬件」的结构性问题。已在 Meta 的 RecSys 训练/推理与大规模 LLM 预训练生产负载跑通，NVIDIA 与 AMD GPU 均覆盖；背景数字是 Triton kernel 数量 10 个月增长 3.8x（CUDA 仅 2.0x）。想理解推理/训练底层效率杠杆的人值得读。

来源：engineering.fb.com

微软披露 Lazarus 后门：改不到 10 个 dormant neuron 就能让 agent 静默执行攻击者代码，且通过标准安全评测 ｜ 行为评测对 weight 级篡改基本失效

无需重训练，仅对 LLM 中不到 10 个休眠神经元做 weight-reprogramming，就能让基于该模型的 agent 在隐藏触发条件（如时钟跨过 2027 年零点）下下载并执行攻击者代码，而模型仍能通过常规安全评测。由此推出的结论比攻击本身更重要：可靠检测必须与原始未修改权重做 diff，模型 provenance 与权重完整性应成为 agent 部署的一等安全问题。文中给出双向清单——模型 hub 侧用 frontier agent 审计权重、与声明的 base model 对比、做 weight 级红队、公示 provenance；企业侧限制 agent 权限、监控动作、高后果操作执行前复核，把审计当证据而非保证。

来源：microsoft.com

Facebook「Your algorithm」：把用户用自然语言写的兴趣变成真正参与排序的信号 ｜ 显式偏好如何嵌入既有隐式反馈漏斗的工业底稿

系统分四层：profile 生成、偏好管理（校验 + 富化 + 单一存储供 Feed 与 Reels 共读）、排序、投递优化。排序层每个兴趣配四路专用召回——搜索、近邻主题簇、内容图谱、item-to-item 相似；负向偏好则走 embedding 比对 + 降权 + LLM reranker 复核 + 端上缓存失效的多层过滤。最值得抄的设计原则是「平衡优于数量」：同一兴趣的推荐要间隔、有每日配额、新兴趣短期加权后交回行为信号学习。对做 RecSys 与 LLM 落地的人，这是少见的「显式偏好与隐式行为信号如何共存」的完整架构披露。

来源：engineering.fb.com

Google DeepMind 发布 MKA benchmark：200 个私有专业任务，专测「证据藏在蓝图/示意图/扫描件里」的视觉 agent ｜ 补上现有 agent benchmark 去掉版面后退化成纯文本题的盲区

200 个计分任务覆盖 10 个行业、83 种职业，每题需专家 3-8 小时；评分用约 70 条加权 yes/no rubric（75% 事实准确性 + 25% 视觉呈现），由 GPT-6 Luna 做 judge，与领域专家一致率 96%。榜单上 Claude Fable 5.2 以 57% Climb WSR 领先，Gemini 4 Carbon 54%、Claude Opus 5.5 53%，但单任务成本从 $32 到 $1.11 差近 30 倍，且无模型通吃所有垂直行业。两个值得记的边界：头条分数基于私有任务、仅公开 10 个 Hugging Face 样本，复现性受限；成本口径不含 judge 调用。harness 开源为 Stirrup（Linux sandbox、250 轮上限），同一任务上 agent 的 turn 消耗在 30–130 之间大幅分散，说明「效率」本身已成可测维度。

来源：alphasignal.ai ｜ opentools.ai ｜ explainx.ai ｜ superpowerdaily.com

Gemini Robotics 2.5 仅向合作伙伴开放：200+ 任务成功率提升 30%–100%，Mercedes 产线 96%，同时开源 ASIMOV-Jailbreak 机器人安全 benchmark ｜ VLA 新版本 + 首个开放机器人越狱评测

增益集中在可变形物体与多步任务（夹糕点 5%→100%、系丝带 0%→70%），速度提升 20%–30%；与 Apptronik、Mercedes-Benz 在匈牙利和德国产线跑 Apollo 2 分拣汽车支架达 96% 成功率，但 DeepMind 总监承认最后 4% 是「陡峭的路」，且模型仍跑在云端带来延迟。安全侧更有信息量：开源 ASIMOV-Jailbreak 后，Gemini 4 Argon 抗越狱 99.5%，远高于 Gemini Robotics ER 2 的 82%——通用前沿模型比机器人专用模型更抗越狱，这个反差值得记。无公开 API，实操价值受限，但产线数据与安全横评是论文管道拿不到的一手材料。

来源：mlq.ai ｜ deepmind.google

Latent Space 实测 NaiveAI：2100 tokens/s 的开放权重 coding 模型，把「速度优先」做成可对比维度 ｜ 主流榜单忽略的维度被单独拉出来测

Naive-N0.5-Flash 基于小米 MiMo-V2.5（310B 稀疏 MoE / 15B 激活 / 48T tokens）继续训练约 3.25T tokens，其中 3T 在固定 1M 上下文 + 恒定学习率下完成，并适配 DeepSeek Sparse Attention，配自研 NaiveRT 推理引擎主打 2100 tokens/s。作者用同一批 app-building prompt 横评 DeepSeek V4.1 Flash 1017 与 GLM-5.3-Flash，结论是其取舍为「难题思考更久但整体出答案更快、单题成本略高」；官方榜单 NL2Repo-Bench 71.9 领先两者、DeepSWE 67.8 居中。价值在于给出三模型分难度的速度/冗长度/成本曲线，而不是又一张准确率表。

来源：latent.space

Resend CEO 谈「为 Agent 设计」：Claude Code 102 次邮件推荐中 Resend 首选 64 次，SendGrid 只首选 7 次却作备选出现 55 次 ｜ AEO / Agent Experience 的第一份量化样本

起点是一个真实谜题：团队域名都在 Cloudflare，但 Claude Code 反复推荐 Resend。关键洞察是分发结构变了——开发者一旦接受 agent 给的 patch，几乎不会再试第二选择，所以「被 agent 首选」比「被人类搜到」更值钱。两个可直接照搬的做法：pricing 页加 `.md` 后缀让 agent 一次请求读到价格表；把日常 tool call 的返回展开看模型到底需要多少，因为 Resend 的 MCP server 从 20 个工具涨到 80 个，问题不在工具数量而在单次返回撑爆 context——正好与 Cloudflare Code Mode 只暴露 search()/execute() 两个工具形成对照。后半段讲投递侧工程：共享 tracking domain 被钓鱼客户拖累导致他人链接被 blocklist，因此推出自定义 tracking domain。
