📊 今日概览

美国 BIS 新规把「远程租算力」正式纳入出口管制，约 750 块 H100 等值即为许可门槛，东南亚算力中转通道就此关闭，全球 AI 股应声重挫——MiniMax 单日跌 18%、智谱跌 13.4%、中际旭创跌 12.3%，半导体 ETF 跌 5.41%。产业侧同日出现多条结构性信号：Anthropic S-1 披露 H1 2026 收入 163 亿美元（去年同期 12 亿）、算力成本占收入比从 251% 降至 48%；OpenAI 启动「嵌入式评估」，让 Apollo、METR、Transluce、Goodfire 四家外部机构深度接触 checkpoint 与训练数据；Perplexity 成立 Frontier Research，投入超 1 万 GPU 做自动研究员。效率方向同样密集：DeepSeek V4.1 Flash 在 Vera Rubin NVL72 上每芯片吞吐达 GB300 的 63–93 倍，微软 TokenEconomizer 给 coding agent 降本 18.4–30.9%。

🔥 趋势洞察

  • 算力管制转向租户维度：BIS 新规把许可条件挂在芯片出货与租户身份而非「云登录」上，跨境训练集群选址与合规成本需重算
  • Agent 成本工程化：Swamp 编译技能降 token 8 倍、微软 TokenEconomizer 降本 18–31%、Together 评测流程把完成率从 67% 提到 96%，优化重心从模型转向工作流
  • 实验室透明度可核查化：OpenAI 嵌入式评估让外部机构拿到实际系统访问权，安全承诺开始有可对照的基准线

🔧 工具与产品

  • Evolving Infra：在线适配 agent 负载的推理框架 - 放弃固定的 prefill/decode 分离。对比 NVIDIA Dynamo 在最多 256 张 GB300 上：延迟降 4.1 倍、P95 TTFT 降 14 倍、收入增 2.36 倍。测试集是 Computer Use、编码、数学 agent 的真实 trace。技术报告与代码已放出 @Mlsys_HaoKang（Evolving Infra 作者）
  • NVIDIA 给出双 DGX Station 本地跑 GLM-5.3 的部署指南 - 走 vLLM，NVFP4 权重全部驻留显存，两张 GB300 张量并行，对外只暴露一个 OpenAI 兼容 API。开启 MTP 投机解码、FP8 KV cache 与前缀缓存 @vllm_project
  • NVIDIA 开源 Nemotron-Labs-Sigma，把连续扩散用于语言模型 - 14 个 3B/8B 检查点。用 16 维平滑 ODE 轨迹支持蒸馏与引导：数学 8 TPF、代码 4 TPF，称精度与多样性都保住 @MardaniMorteza（NVIDIA 研究员）
  • Swamp 把重复技能编译成工作流，token 降约 8 倍 - 代码决定下一步，模型只在需要判断的步骤被调用。官方把 code review 技能搬到 Codex 与 Swamp 对比：460 万 token / 23 个 agent / 12.8 分钟 → 50.6 万 token / 3 个 agent / 6.6 分钟。兼容 Claude Code、Codex、Cursor 等 9 个外壳 @_avichawla（AI 教程作者，DailyDoseofDS）｜同方向另有微软研究院开源插件 TokenEconomizer，复用历史会话经验压 token 成本 @MSFTResearch
  • ComfyUI v0.36.0 给 MiniMax H3 视频 VAE 提速 - NVIDIA GPU 上编码最高 2.2 倍、解码 1.4–2.7 倍；1344x768、129 帧往返从 24.3 秒降到 12.7 秒。改动是融合编码 kernel 去掉卷积间多余访存、int8 解码器不落中间结果 @ComfyDevs（ComfyUI 团队账号）
  • NVIDIA 在 CoRL 2026 发 GR00T 2 人形机器人世界行动模型 - 配套 RLWRLD（机器人学习初创）与 UC Berkeley 基于 Isaac Lab-Arena 的开放工业基准，任务含接线缆、装小零件。同期 Roozbeh Mottaghi（机器人视觉研究者）开源物体中心 3D 世界模型，从短视频预测物体与手的未来运动 @NVIDIAAP（NVIDIA 亚太账号）｜@RoozbehMottaghi

⚙️ 技术实践

  • DeepSeek V4.1 Flash 在 Vera Rubin NVL72 上每芯片吞吐达 GB300 的 63–93 倍 - 组合为 NVIDIA Dynamo + vLLM，跑 SemiAnalysis 的 AgentX 基准。按每用户 400 tok/s 计时，每芯片总 token 吞吐是 GB300 NVL72 的 63.4 倍；600 tok/s 时为 93.3 倍 @vllm_project
  • Databricks Genie 在企业数据任务通过率 91%，两个前沿 agent 为 45% 和 58% - 与 Turing（AI 服务公司）合建基准：任务要用散在 notebook、dashboard、存量 SQL 里的业务知识，不能只查表。每任务跑 5 次。Genie 用不到一半 token、快 3–4 倍。差异来自 Genie Ontology 先检索业务定义，而非只看表结构 @databricks
  • Together AI 今年把去年做的 megakernel 删了 - 团队去年参与推出首批整模型 megakernel，现认为该抽象过度复杂、不总是好优化目标。转向 Torch Compile 与 agent 自动调优的 Together Compiler，称最高 2.6 倍吞吐 @dylan__lim（Together AI 工程师）｜@togethercompute
  • Together AI 公开 agent 评测流程，任务完成率从 67% 升到 96% - 做法是每轮定约 10 个代表任务，在沙箱里跑 Claude Code，每任务测 baseline、MCP、skills 三种配置，再按轨迹回改文档和 API @togethercompute
  • Observer Agent：学你什么时候真的需要帮助 - 持续从工作模式和隐式反馈里学主动介入时机，在三个模型骨干上主动时机 F1 提升 2.4–3.0 倍。agent 与训练、推理引擎协同设计，跑在 NVIDIA DGX Spark 一类本机，屏幕观测不出设备 @EchoShao8899（Deep Personalization 一作）
  • SpecPilot 让机器人策略推理提速 3.84 倍，无需训练 - 用 Qwen3.8-27B 当机器人策略跑 LIBERO 任务，完成时间从 189 秒降到 49 秒，解码从 71 tok/s 提到 241 tok/s @li_kunjun（SpecPilot 作者）
  • Sakana AI 发布日语金融基准 JFinBench，共 321 题 - 取自 2026 年版 6 项日本金融资格考试（注册会计师、税理士、FP 一级等），含税额计算、论述与读图题。构建用 human-in-the-loop agent 流程：编码 agent 转 PDF，人工全量复核约 12 小时。测 12 个 LLM，开源权重模型在主流基准已接近闭源，在 JFinBench 上差距明显，主因是日本制度知识不足而非算错 @SakanaAILabs（日本 AI 实验室）

美国 BIS 新规把「远程租算力」正式纳入出口管制：境外数据中心向中国总部企业提供大规模算力须许可，约 750 块 H100 等值即为门槛 ｜ 算力地缘的规则级拐点

多家媒体交叉报道同一件事，细节互补：规则以临时最终规则形式发布，把许可条件挂在芯片出货、转移与再出口上而非「云登录」——绕开了「云计算不算出口」的法律障碍；门槛口径为向可能让 D:5 国家总部企业获得超过 1200 万累计 TPP 算力的数据中心出货先进芯片需申请许可，TechCrunch 估算约合 750 块 H100/H200（非规则原文数字）；印尼、马来西亚、新加坡、泰国、巴西五国总部企业出口亦需许可，已服务受限客户的数据中心有 90 天过渡期。对从业者的实际含义：东南亚「算力中转」灰色通道关闭，跨境训练集群的选址、租户身份核查与月度报告将成为云 GPU 运营商的合规负担，需重算成本模型。

OpenAI 启动「嵌入式评估」第一阶段：Apollo、METR、Transluce、Goodfire 四家获准接触 checkpoint、源码、训练数据与监控系统 ｜ 实验室内部透明度首次变成可核查机制

White House Accord on Super Intelligence 承诺下的首个落地动作。四家分工清晰且互补：Apollo Research 分两阶段验证四条主张（训练未激励 subversion、红队无法诱发、内部使用未出现、subversion 推理可被检测）；METR 评估迄今最大 RL run 的 misalignment 并做 monitor 压力测试；Transluce 审 post-training alignment eval 的质量与覆盖度；Goodfire 用其平台做 interpretability 训练监控。外部专家可长时间深度接触内部资源并直接与负责研究员对话——这是「独立评估如何嵌入实验室内部」的一手样本，可作为判断后续各家安全承诺含金量的基准线。

来源：openai.com

Paul Christiano 给出具体概率与政策主张：若无减速，一年内有 1/3 概率出现能力足以推翻政府的超级智能，主张先锁权重再谈算法进展 ｜ 对齐圈最重量级的一手判断

Dwarkesh 访谈 ARC 负责人、RLHF 发明者、现任 OpenAI 董事 Christiano。核心不只是那个 1/3 概率，而是他给出的政策排序：各实验室应在能锁住权重与研究机密之前暂停算法进展，否则中国可直接窃取超级智能、实验室届时想慢也慢不下来。他还推演 intelligence explosion 期间的训练方式、为何纯数据中心内训练的系统也让人无从竞争，以及对齐方案现状——修 reward hack、建更好的 grader 只够撑几代模型，目前没有任何单一方法有超过五成把握控制超级智能，只能寄望 AI 自己在爆炸过程中解出这个问题。适合想给「AI 风险时间表」找可引用锚点的人。

来源：dwarkesh.com

Stratechery 用「讣告」体拆解 Nvidia 三重护城河如何在 LLM 时代同时失效 ｜ 平台护城河的通用分析框架

以 Jensen Huang 卸任、Nvidia 失去全球最高市值为假设前提做思想实验，核心论点是三条护城河同时被侵蚀：CUDA 因开发者精力上移到 LLM API 层而失去锁定力；Anthropic 被迫学会在 Trainium/TPU 上训练，证明前沿模型可以完全去 Nvidia 化；最致命的是 LLM 写软件的能力会让任何软件护城河自然干涸。文章还还原 Huang 作为「一人协调函数」如何靠高频 keynote 与亚洲供应链饭局锁定产能，以及因芯片禁令只守字面不守精神最终被政治反噬的路径。虽是虚构推演，但给出的是可复用的「技术栈上移时平台护城河如何瓦解」mental model，且结论反直觉。

来源：stratechery.com

AWS 把多 Agent 协调定性为分布式系统问题：10 步各 95% 可靠串联后端到端只剩 59.9%，给出两层模式分类与制造业式约束 ｜ 多 Agent 选型底稿

失败很少源于模型本身，这是全文最有用的框架。Tier 1 确定性控制流（顺序流水线、条件工作流、条件路由、并行工作流）与 Tier 2 运行时由模型选路，建议默认从 Tier 1 起步、仅当子任务在过程中才浮现时升级到 Tier 2。还借用制造业的 takt time、安全边界、边缘数据与班次周期来约束架构，并单列无界迭代等昂贵反模式。对正在判断「是否真的需要多 agent」的团队，这是一份可直接对照的选型清单，与已有的 Agent 可靠性 checklist 互补而非重复。

来源：aws.amazon.com

微软开源 TokenEconomizer：不改 agent 与模型，靠仓库历史 session 日志给 coding agent 降本 18.4–30.9% ｜ 可直接接入的降本插件

先做的浪费画像很有说服力：仓库积累 5 个任务后 30% 工具调用在重复早前动作、每轮下发 23 个工具描述有 16 个从未被调用、17% 失败任务吃掉 32% 成本。三类干预分别是 micro-skills（一行式仓库知识笔记，需多次 session 确认才写入、被反证则退役）、tool pruning（按历史剔除不用的工具，保留核心命令/编辑工具且可恢复）、failure-loop intervention（judge model 判定是否真卡死，卡死给换路提示，仍卡则告警）。277 个真实 bug-fix 任务上多款 coding agent 每个仓库都降本、成功率基本持平，且已计入插件自身模型调用开销——工程可复现性比多数 agent 优化论文强。

来源：microsoft.com

BFL 核心团队讲清 FLUX 3 为何从图像走向视频+音频：静帧给位置、视频给轨迹、音频给撞击时刻 ｜ 视觉智能的训练信号论

Latent Space 对谈 Andreas Blattmann（Latent Diffusion 共同发明人）与 Dustin Podell（SDXL 一作、FLUX Kontext 负责人）。三种信号联合训练是 FLUX 3 同时训视频与声音的理由。文中另有两个高价值工程细节：移动镜头迫使模型补全物体背面，是比单帧逼真度更好的物理理解测试；逐帧独立超分会导致播放时细节闪烁，因此必须做时序一致 upscaler。以及自回归（一次学全部 token）与扩散（蒸馏到少步采样）在「训练付费 vs 推理等待」上的取舍。Dustin 的 Kontext 早期实验（几小时训练让模型把 logo 画到衬衫上）展示了如何用小实验决定大投入。

来源：latent.space

Import AI 481：FrontierML 首次把「给 agent 一笔钱，看它能否把钱换成模型性能」做成端到端 benchmark ｜ 资本→能力的新标尺

来源：importai.substack.com
