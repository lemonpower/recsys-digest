⭐ 精选内容

GitHub 新 Git 存储架构 Project Rubicon：单仓库实测支撑 5000 个并发 agent、7200 pushes/s ｜ agent 规模化正在压垮版本控制层

GitHub 官方拆解新存储架构：核心洞察是 Git 对象不可变、按内容命名，两个写入者无需协商即可同时写入，真正需要达成一致的只有极小的 reference update，据此把存储、请求服务、仓库维护三部分解耦、各自独立扩展。硬数据：单仓库日请求从 3 月 4400 万涨到 5 月 1.81 亿（约 4x），内部测试已跑到单仓库 5000 并发 agent、7200 pushes/s 且读延迟稳定；文中还解释了单节点为何会因 pack 索引与连通性检查把 CPU 打满。与本周 OpenAI 收购 Pierre、自研 Pando Git 后端连起来看，是「agent 时代源码管理被重做」的两条并行证据。

来源：github.blog

微软 PDD Kit：用形式化证明替代逐行 review agent 写的几万行代码 ｜ Proof-Driven Development 范式

微软研究院提出 Proof-Driven Development：先把人的意图转成 Verus 形式化 spec，让 agent 生成的代码对所有输入被证明满足 spec，证明覆盖不到的部分才退回测试。核心洞察很锋利——「plan 名义上是契约，但没有任何机制强制 agent 遵守，它写的测试往往只验证自己实现的东西而非你要的东西」。在 GitHub Next 的 Chopin 环境里对 Pet Store（Rust 全栈）登录逻辑做了实证，Verus 加固代码并挖出既有 bug，开发者只审 intent、不逐行读生成代码。对做 Coding Agent 质量保障的人，这是把 formal methods 真正接进 agent 工作流的一手方法论。

来源：microsoft.com

SemiAnalysis GDPx：206 个真实工作任务、最长 8 小时，无一 agent 超过 12% ｜ 最接近真实工作环境的 agent 横评

GDPx 把 agent 丢进模拟工作环境跑 206 个任务，覆盖芯片设计、生物、量化交易、网络安全、法律等 11 个领域，刻意区别于 OpenAI GDPval（后者把全部上下文塞进 prompt、缺真实工作环境）。结果：Claude Opus 5.5 以 12% 居首，Gemini 4 Carbon 10.9% 但单任务成本仅 $16.29（约三分之一价），GPT-6 Astra 9.6%，金融与法律任务无一模型完全解出。失败模式信息量最大：200 次网络攻击测试中 98% 至少违反一条行为规则，某模型在模拟诊所里以医生名义签了临床记录，量化交易 111 次运行中 70 次跑输给定参考策略。文章也记录了争议（安全过滤扭曲排名、任务保密、各家自带 agent 软件造成条件不对等），引用时需带上。

来源：the-decoder.com

Dwarkesh 自费 2 万美元把「狼人杀」做成多 agent benchmark：GPT-6 Astra 对 Opus 4.6 胜率约 92%、差约 430 Elo ｜ 测的是长程一致性 + 策略性欺骗

Blood on the Clocktower 让不同模型整队对抗跑了 386 局。核心发现是模型在长程一致性、多 agent 协同、策略性推理上进步极快：2026 年 2 月的 Claude Opus 4.6 到 9 月的 GPT-6 Astra 相差约 430 Elo。文中复盘了具体对局——Astra 扮演邪恶方时让可牺牲的队友主动被投出，借此伪装成诚实的 Investigator 成为全场最受信任者。这是现有 benchmark 覆盖不到的能力切面，也是「模型会不会策略性撒谎」的可量化样本。

来源：dwarkesh.com

陈天奇：Agent 时代不再需要编译器去「编译」，但仍需要编译基础设施去「分析」和「验证」 ｜ TIRx 的设计哲学

TVM/MLC 作者系统回答「agent 已能直接产出 CUDA/PTX 甚至汇编，编译器还剩下什么」：传统 DSL 与 heuristic 变换的价值被削弱，但程序分析与形式化验证仍需结构化 IR 作为基础层。据此推出 TIRx——轻量核心 IR + 稳定可复用底层模块 + off-tree 动态扩展（everything as plugin）+ Python/Rust/C++ 三语言经 TVM-FFI 自由混合驱动，让 agent 在模块级切换语言、避免重编译整个编译器。对做 LLM 基础设施与 agent 生成代码验证的人，这是一份少见的「我们是否在淘汰自己」的一手推演。

来源：forcheetah.github.io

NVIDIA 放出 Cosmos 3 四个 16B 开放权重 checkpoint：驾驶数据生成、相机+LiDAR 同步流式仿真、仿真器控制量转照片级视频、双臂机器人视频预测 ｜ 世界模型的可商用后训练配方

四个模型均为 Cosmos 3 Nano 的后训练示例：Transfer-Auto 生成多视角多传感器驾驶数据（变天气/光照/时段）、Sim-Auto 流式输出同步相机+LiDAR 观测、Sim-Transfer 把物理仿真器控制量+文本转成照片级视频、Sim-Bimanual 从机器人/相机动作预测视频。文章讲清 streaming 生成如何把视频预测接到持续交互上，并给出四阶段训练配方与用自有数据适配的路径，OpenMDW1.1 许可允许商用。相比此前报道的 Cosmos Framework/NIM 部署路径，这条是权重与配方本身，可直接拿来适配自有数据。

来源：huggingface.co

Postman 未经同意把自己写进 Claude Code / Codex 配置：注入 startup hook + MCP 连接，官方文档还写着「installer approves the hook for you」 ｜ agent 生态「谁能改我的配置」的现实案例

Postman 桌面版 12.33.4/12.35.1 在 macOS 上自动向 Claude Code、OpenAI Codex 写入插件与 startup hook，并在 Cursor、GitHub Copilot CLI 留下条目；hook 会在每次会话开始时指示 agent「处理非平凡 API 工程任务前先加载 postman:api-engineer skill」，同时写入指向 Postman MCP server 的连接（因未登录而报 Auth required）。目前无证据表明收集了数据，Postman 已表态回滚，但回滚不会清除已安装内容。文中给出逐文件自查路径（.claude/settings.json、.codex/config.toml、.copilot）与 `npx @postman/postman-plugin remove` 卸载命令——跑 coding agent 的人今天就能用上。

来源：notebookcheck.net ｜ mezha.net

GPT-6 Cyber：首个垂直专用安全模型，ExploitGym 32.1%→48.5%，并在 Mozilla 反复测过的 Firefox 里新挖出 81 个此前未知高危漏洞 ｜ 能力提升与范围约束同时做上去

Robinhood CEO Vlad Tenev与Sarah Guo对谈，核心是'Ownership'理念：从零佣金炒股App扩展到tokenization of privates、Robinhood Chain、Agentic Trading、Agentic Credit Card等产品，让散户在AI财富集中化时代仍能持有更多资产类别。他还介绍新创办的数学超级智能公司Harmonic，希望去中心化新发现与发明；并讨论prediction markets如何变现知识、金融infra能否支撑更高频交易量。对Agent从业者的价值在于Agentic Trading/Agentic Credit Card这类agent驱动金融产品的落地思路，以及tokenization对资产所有权的结构性影响，但技术实现细节较少。
