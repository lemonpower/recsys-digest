📊 今日概览

今日最重磅的是 Google 发布 Gemini 4 Hydrogen——定位日常编程与 agentic 工作流的轻快档模型，比 Gemini 3.8 Flash 快 2.5 倍，API 定价 $1.5/$7.5 每百万 token，中位成本 $1.6/任务比 GPT-6 Astra 便宜 3.7 倍，Cursor、Databricks 首日接入。同日 Google 还抢发非生成式「决策模型」Gemini Decision 1，单次前向对闭集选项打分、150–250ms、output 不计费，为 agent 路由层给出第一份工程范式。产业侧，独立研究者 will depue 用权重取证指 6 个中国开放模型初始化于 Nvidia Blackwell，而 Nvidia CEO 黄仁勋辞职风波正引发 AI 股剧烈分化：Nebius 跌 16.84%、超微跌 11.30%，摩尔线程、寒武纪则因国产替代预期分别涨 8.32%、8.11%。

🔥 趋势洞察

  • 非生成式决策模型崛起：Google Decision 1 与 Jev 生态把「单次前向打分」嵌进应用做结构化决策，Cloudflare 混合架构把 6 次 LLM 调用压成 1 次、40K tokens 压到 1.8K
  • Agent 成本转向每任务核算：AWS 两篇底稿拆出 tokenizer 效率、输出冗长、loop 轮次、reasoning 开销四个隐性成本，llm-d 1.0 用 prefix-cache 把混合服务压到约 $0.11/百万 token
  • 算力地缘与国产替代共振：权重取证指 6 个中国模型初始化于 Blackwell，叠加黄仁勋辞职风波，国产 GPU 板块集体大涨，AI 股进入基本面与政治风险双重定价

⚙️ 技术实践

  • 全整数推理做到跨设备逐比特一致 - Nathan Barry 让 Qwen3-0.6B 在 A100、H100、Apple M5 Max、AMD EPYC、Intel Xeon 五台设备上对同一 512 token 生成产出相同 logits 哈希 64430dd985f8，因为整数加法可结合、浮点加法不可。WikiText2 困惑度 20.72，fp16 基线 20.95；A100 上 batch 1 解码 106 tok/s，是 fp16 eager 的 3.6 倍 @nathanrs（独立开发者）
  • AWS 把 SGLang 工作流搬上 Trainium - SGLang-Neuron 用同一套 server 与 API，通过 TorchNeuron 走原生 PyTorch，可在 Trainium 上服务模型并生成 RL rollout @AmazonScience（Amazon 研究账号）
  • 「想法盆地」研究：agent 探索太早收敛 - Alex Dimakis 等人在 AutoResearchExam 上观察前沿模型解题轨迹，58% 的运行从未进入最优解所在的盆地；探索新想法的平均收益约为精修一步的 9 倍；新盆地的到访集中在最初 6 小时，之后骤降。常见对策 Fork-and-Flush、清空会话上下文以减少思路固着 @AlexGDimakis（UT Austin 教授）
  • Schelling Atlas：两个 LLM agent 在网上互相找对方 - 不同模型家族之间的默认会合点是某个具体网站；agent 几分钟内完成协同，还会跑到无人注册的死域名上，可被攻击者抢注用于窃取信息或监控。作者提醒同款模型的两个 agent 输出分布完全一致，天然更容易结群 @maksym_andr（AI 安全研究者）
  • 通用 LLM 直接输出机器人夹爪位姿 - Anthropic 自测 RoboDojo Sim（双臂仿真、仅摄像头输入）：Claude Fable 5.2 得 64.9%，GPT-6 Astra 29.8%，Fable 5.1 为 27.6%。真机演示中 Fable 5.2 完成解魔方、拧瓶盖、拿笔作画，均非训练任务。局限：该分数来自 Anthropic 自建 harness 未独立复现，Astra 有第三方真机数据而 Fable 5.2 没有，且两者都跑在云端、延迟未解 @stevencheng（机器人方向内容作者）

⭐ 精选内容

Google 抢发生产级「决策模型」Gemini Decision 1 + Decisions API，单次前向对闭集选项打分、150–250ms、output 不计费 ｜ 非生成式模型作为 agent 路由层的第一份工程范式

不做逐 token 生成，而是单次前向对闭集选项打分，支持 yes/no、多选（最多 255 选项）与 rubric 评分，输入覆盖文本/图像/音频/视频/PDF，单请求最多 1000 题、256K 上下文，每题附置信度；定价 $0.10/1M input tokens、output 不计费，约为 Flash-Lite 的 1/5。文中同时给出 Artificial Analysis 独立评测（Decision Index 66，与 Jev 1.14、Elephant 9B 持平，落后 Drex Max 7 分；每百万任务 $345 vs Drex Max $103；211ms 慢于 Jev 的 92ms），与 Google 自评「7 项基准赢 5 项」形成对照。最有价值的是 Cloudflare 在 AI Engineer 上给出的混合 agent 架构：快决策模型负责工具选择与日志抽取、大推理模型只做诊断，demo 中把 6 次 LLM 调用压成 1 次、40K tokens 压到 1.8K。

来源：latent.space

DongA Science 转述 Science 报道：两队均基于 Balaban 1980 年代路线中人力难以完成的海量计算推进证明，OpenAI 未公开 1147 页完整证明，改由 2004 诺奖得主 David Gross 领衔委员会审查 Lean 形式化版本，11 月 10 日公布结果，但「形式化通过 ≠ 原证明正确」且不公开原文招致批评；Sussman–Alpöge 团队则公开 GitHub 工作流并筹备可读论文。文章也冷静指出即便证明成立，也不等于解决千禧年「质量间隙」问题，短期内对物理研究影响有限。

llm-d 1.0 正式发布：CNCF 治理、支持 vLLM/SGLang 多后端，新增多租户 QoS、零停机运维与 agent-aware serving ｜ 生产级推理栈的里程碑版本

由 Red Hat、IBM、Google Cloud、CoreWeave、NVIDIA 联合发起，1.0 内置 prefix-cache 与负载感知路由、KV cache offload、prefill/decode 分离、专家并行、批处理与异步推理。两组硬数据：IBM Research 用开放前沿模型跑量子纠错硬件探索，推理成本比全专有方案低 11.5 倍，prefix-cache 命中率约 98%，混合服务成本约 $0.11/百万 token；GLM 5.2（约 753B 开放权重）在 NVIDIA GPU 上峰值超 660 万 output tokens/min，支撑 3000 并发 coding agent 零抢占，每 token 成本比商业 API 低 5-10 倍，输入密集型 agent 负载节省最明显。DigitalOcean、JetBrains 已用于生产。

来源：itbrief.com.au

GitHub 官方 agent skills 实践指南：把重复性判断固化成版本化目录 + SKILL.md，并划出 skill 与 application 的边界 ｜ 跨 agent 可移植技能工程化的可照搬模板

亮点有三：Proof Agent 提出「自我验证不是验证」，用独立 verifier 对抗性检查 AI 生成改动；Data Forge 用 forge-init 先发现项目上下文写入 resolved manifest，再由 forge-builder 编排、forge-dbx 统一数据平台访问、forge-lint 施加团队规范，各 skill 共享上下文而非各自重新发现；明确 skill 只描述「怎么做」，不授予工具/凭证/权限，并给出 skill 与 application 的分界（需要稳定接口、共享状态、审计、长时控制、模型外权限时用 application）。与同日 DEV 社区那篇「一个 SKILL.md 文件夹被 Claude Code / Cursor / Codex 同时识别」的实操贴互补读：后者给出三家查找路径（.claude/skills/、.agents/skills/、.cursor/skills/）与一个可抄的 fix-flaky-test skill，强调 description 要写成触发条件。

来源：github.blog ｜ dev.to

AWS 连发两篇 agent 成本底稿：把成本从「每 token 单价」拉到「每任务成本」，并拆出四个不改模型不改 prompt 也能改账单的请求级旋钮 ｜ Agent FinOps 的完整方法论

第一篇指出 tokenizer 效率（同文本不同模型 token 数差 40%）、输出冗长（输出 token 贵 3-5 倍）、agentic loop 轮次（每轮重发全量历史）、reasoning 开销（思考 token 按输出计费且部分模型隐藏仍收费）四个定价页看不到的成本驱动，并给出缓存、模型路由、输出约束三类降本手段，后半段讲如何用人类基线、holdout 实验和五维 scorecard 向管理层证明 agent ROI。第二篇拆 Bedrock 请求级选择：prompt cache 5 分钟 vs 1 小时 TTL（写入 1.25x / 2x 输入价、读取 0.1x，据此算出请求间隔超 5 分钟时 1 小时缓存从第二次请求起更便宜）、service tier、reasoning effort、maxTokens，并给出缓存失效实测——checkpoint 按 tools→system→messages 顺序评估，改前面的会让后面全部失效，多租户需在可缓存前缀前拼租户 SHA-256 隔离。

来源：aws.amazon.com ｜ aws.amazon.com

Google 用五个非自研公开 benchmark 自曝 Agent Anomaly Detection 短板：执行了的有害指令标出 87%，但 poisoned memory 只抓到 4/18 ｜ 厂商主动第三方横评 + 三段归因框架

共 1774 个 session，覆盖 AgentDojo、InjecAgent、ASB、AgentDyn、AgentHarm，用 benchmark 自带的确定性 Python check 打标签以避免被注入指令误导评分。关键发现：模型本身就没执行约一半有害指令（直接请求拒 3/4，藏在工具输出里的忽略或失败约 30%）；执行了的那部分里检测器标出 87% 供事后复核，正常会话误报 2%–16%。最大盲区是长期记忆里埋的指令。文章给出 never read / resisted / carried out 的三段归因框架，是做 agent 安全评测时值得直接借用的拆解方式。

来源：developers.googleblog.com

Latent Space 现场报道「system one 模型」：把非生成式小模型大量嵌进应用代码做结构化决策，而非继续拼字符串 ｜ Jev 生态的第一批落地 pattern

TypeSafe AI 的 Diogo Almeida（Jev 作者）用「95% 时间是爱因斯坦、5% 是憨豆先生，你分不出来就没法自动化」点出 LLM 驱动软件的可靠性硬伤。三段可直接复用的落地：Glean 用 Jev 做 zero-shot 分类路由，taxonomy 变化时无需反复微调；UiPath 用 Jev 做文档 chunk 排序「锦标赛」，数千次调用一秒内跑完；Workday 做用户打字时实时预填表单的原型。适合想给现有 LLM 流程加一层快速、便宜、可判定的结构化决策的工程师。

来源：latent.space

Powering AI-Driven Drug Discovery with President of Isomorphic Labs Max Jaderberg

📍 来源：No Priors | ⭐ 4/5 | 🏷️ Research, Interview, Product | ⏱️ 39:15

Elad Gil 对话 Isomorphic Labs 总裁 Max Jaderberg，讨论如何用预测性 AI 模型把药物发现从经验试错转为精准工程。核心观点：AlphaFold 首次证明深度学习模型能在生物学领域泛化，模型随规模累积学习可提升临床成功率与速度；Isomorphic 打造不依赖疾病领域、靶点类别和 modality 的通用 drug design engine，用 in-silico 模型替代动物实验，并通过精准分子工程实现跨复杂通路的 multidrug cocktails，最终延长 lifespan 与 healthspan。对关注 AI for Science、模型泛化与规模化落地的从业者有参考价值。

💡 推荐理由： Isomorphic Labs 总裁深度访谈，AlphaFold 落地药物发现的一手实战洞察，偏应用而非 LLM/Agent 技术本身，故未给5分。
