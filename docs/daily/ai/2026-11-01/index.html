  • RAG 两条路线：文档树导航 vs 先修检索链 - Cornell 与 ASAPP 的 retriever-free RAG 把文档组织成树，用决策模型 Jev 1.13（只输出是/否概率、不生成文本）逐层筛，Natural Questions 上 top-1 含答案 65.4%；嵌入检索加 8B 重排为 48.0%，GPT-5 重排 60.8%。中位检索不到 2 秒，但各方法计时环境不同 @akshay_pachaar（NLP 教育者 / DailyDoseofDS 创始人，转述论文）。LangChain 社区的方案则先修检索：contextual embeddings + BM25 + reranker，在 Anthropic 评测中失败检索减少 67% @LangChain
  • dax：DeepSeek Flash 已原生量化，专家层就是 FP4 - 他称再做后量化几乎拿不到收益 @thdxr（SST 创始人 / OpenCode 作者）

⭐ 精选内容

Arca 的 AI 负责人复盘长周期金融 Agent：agent 反过来 prompt 人，per-client 持久 memory + 自建 harness 做模型路由 ｜ 长周期 agent 的工程范式

核心洞察是「agents prompt people more than people prompt agents」——agent 承担绝大部分后台工作，人类顾问握最终决策。工程上可抄的点密集：金融任务单个可跨 10 天、多决策点多次 handoff，因此自建 per-client 持久 memory 追踪「已发生/待跟踪/谁负责」；自建 harness 按内部 benchmark 自动选模型（Claude 为主），保留随时换供应商的自由；安全护栏全部确定性实现，交易与资金流动一律交人类，agent 只做分析与提案；agent 写的代码先转成严格格式、丢弃原代码、在格式层装护栏后才触达后端数据；再用 meta-agent 分析人类反馈与 agent trace 反向优化 harness。对做 agentic 落地的人，这是一份少见的"高风险领域如何划边界"的完整样本。

Parameter Labs 完整拆解 ChatGPT HTML preview 沙箱逃逸链，OpenAI 已修复并付 5000 美元赏金 ｜ agent 工具沙箱的高密度反面教材

攻击链环环相扣：MathLive 虚拟键盘的 postMessage 接收端用 innerHTML 写入父页面且不校验来源 frame → 任意 sandboxed iframe 可注入 HTML → innerHTML 虽不执行 script 但可插入不带 sandbox 的新 iframe → OpenAI 的 CSP 只允许少数域名加载脚本，其中 YouTube oEmbed 端点可被用来反射回可执行 JS → 拿到 JS 执行后即可调 API 读私有数据并经图片引用外带。最终可构造一个共享链接，任何已登录用户点开即被窃取数据或代其操作。对做 agent 工具沙箱、iframe 隔离、CSP 白名单的人，读完能立刻对照自查。

免费 Colab TPU v5e 上把训练做到比 T4 快 44 倍：加速拆解与 TPU 上 MoE 的真实成本 ｜ 硬件换代 vs 框架 vs kernel 的收益归因

10 亿 token 从约 6 天降到约 3 小时。加速拆解很有参考价值——硬件换代约 7.7×、切到 JAX 约 4.5×，而自定义 kernel（splash attention、Megablox、数据搬运）合计只贡献约 1.08×。splash attention 在 seq=8192 时比默认 flash attention 快 8.8×（8.05ms vs 70.6ms），但 seq=512 时几乎无收益，说明收益取决于 attention 是否为瓶颈。反面结论同样有用：TPU 上细粒度 MoE 的小专家很贵，每专家 8→64 token 时延几乎不变（约 24μs），需 400+ token/专家才接近 90% 峰值效率，最细粒度成本可达 dense 层的 6 倍。注意是免费环境单点实验，外推需谨慎。
