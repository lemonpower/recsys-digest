📊 今日概览

今日最重磅的产业信号来自政治而非技术：美国中期选举 10 个州 41 项数据中心公投几乎全被否决，德州选出承诺暂停新建数据中心的州长，AI 基建的约束正式从"算力→电力"迁移到"政治"，维谛技术单日暴跌 12.89%、瑞致达跌 13.83% 正是市场对这一变量的即时定价。技术侧，Kimi K3.1 Pro 放出权重（1M 上下文、3T 级，vLLM Day-0 支持），Together Compiler 用 agent 持续编译推理、比最佳配置快 2.6 倍，OpenAI 则披露自主流水线在 Linux 内核确认并修补 948 个提权漏洞、API 成本约 120 万美元。国内半导体链午后主力资金大举进场，科创50 放量涨 9.92%。

⚙️ 技术实践

  • Together Compiler：用 agent 持续编译优化推理，比 InferenceX 最佳配置快 2.6 倍 - 单次编译用 2 个节点、24 小时内出结果，MiniMax M3.1 在 B200 上 1111 TPS，DeepSeek v4.1 Flash 在 GB300 上 1205 TPS（batch size 1）。实验吞吐比此前的 agent 优化系统高 252 倍，现每天服务数万亿 token，流量变化后几小时内重新编译。覆盖 NVIDIA、AMD、Trainium2 @togethercompute｜@simran_s_arora（Together AI 研究高级副总裁）｜@realDanFu（同）
  • ForgeKernel：自演化 agent 优化 GPU 算子，DeepSeek V4.1 FlashMLA 实时提速 9.8% - 把架构设计与代码实现拆开，遇到结构性瓶颈时回头改 work partitioning、dataflow、pipeline，而非只在固定架构内调参。发现的硬件机制先在目标硬件上独立验证，再入库跨算子共享。NVIDIA GPU 上几何平均 1.10 倍，CANN-Bench 2.0 三个榜与 SOL-ExecBench FlashInfer-Bench 均排第一 @_LiYuXuan_（论文一作）
  • NVIDIA 论文：频繁压缩上下文几乎不掉分 - Claude Opus 4.5 每次只保留一个动作的上下文，SWE-bench Verified 得 70.2，用完整历史是 70.0；峰值上下文中位数从 32K 降到 8K token。对话末尾做一次压缩后，分数从 70.0 升到 74.8。成本侧的理由是越靠后的 token 生成越贵，前沿开放权重模型上最多差 7 倍 @omarsar0（NLP 教育者 / DAIR.AI 创始人）
  • AI 找漏洞三连：OpenAI 修 948 个 Linux 提权漏洞、Mistral 派 133 个 agent 修 Django CVE、Cloudflare 开源审计流程 - OpenAI 的自主流水线单次运行验证并为 948 个本地提权漏洞生成补丁，API 成本 120 万美元。Mistral Large 4 走完 triage、复现、打补丁三步。Cloudflare 放出六阶段 skill（测绘代码库、找漏洞、逐条挑战候选、记录、验证、报告），把编码 agent 变成审计团队 @OpenAI｜@MistralAI｜@CloudflareDev
  • 朴素权重扰动做 agent 后训练：Qwen3.5-4B 在 Terminal-Bench 2.1 从 12.1% 升到 21.1% - 超过官方 Tmax RL checkpoint 的 18.2%。不用 credit assignment、critic、masking，种群规模约 30。作者认为这条路线对长程 agentic 后训练价值最大 @catherineliangq（论文作者）
  • 低成本机器人操作学习两件套：CMU 的 1.5 万美元人形机器人 Pixel、TouchBridge 触觉演示迁移 - Pixel 配 Pixel-UMI 训练框架，做环境感知的全身移动操作。TouchBridge 只用人类演示，在 4 个真实任务上平均成功率 72.5%，用等量遥操作数据是 77.5%；人类数据采集快 7.0 倍，重定向不需要物体网格、位姿估计或物理仿真 @deepakpathak（CMU 教授）｜@Gu__Zhang（论文一作）

AI 基建的约束从算力/电力迁移到「政治」：中期选举数据中心公投几乎全被否决，Stratechery 给出「全球化 vs 建数据中心需要许可」的解释框架 ｜ 反数据中心浪潮成为 AI 扩散的最终瓶颈

2026 中期选举中 10 个州共 41 项数据中心相关公投几乎全部被否（唯一例外北达科他州 Harwood），俄亥俄一州占 21 项；德州选出承诺暂停新建数据中心的州长，两名支持数据中心的市长被罢免。Stratechery 的核心洞察：当年制造业外迁时受影响社区毫无话语权，而建数据中心需要许可，于是这些人在 AI 上第一次拿到否决权并正用它表达不满；反数据中心浪潮的最大受益者可能恰是前沿实验室，因为许可壁垒抬高后来者成本。TIME 补充 NBC 出口民调 56% 选民把 AI 与数据中心列为投票关键因素，民主党砸超 1 亿美元广告攻击对手与 Big Tech 关系，加速主义超级 PAC 投入未奏效。对从业者，这是「算力→内存→电力→政治」约束迁移的一手样本，也是判断数据中心选址与算力供给节奏的新变量。

来源：stratechery.com ｜ cnbc.com ｜ theguardian.com ｜ time.com ｜ nytimes.com ｜ usatoday.com

OpenAI 自主漏洞研究流水线：scout + analyst 双 agent 跑完扫描→验证→可利用性评估→补丁生成，在 Linux 内核确认并修补 948 个本地提权漏洞，API 成本约 120 万美元 ｜ agent 在安全垂直的端到端工程复盘

文章给出逐段成本拆解，并抛出几个反直觉结论：模型越强所需编排越轻、维护者打补丁速度很快、模型还能发现新的利用手法，甚至指出测试基础设施本身存在漏洞。对做 agent 编排、eval 与安全自动化的团队，这是少见的「四段流水线 + 成本结构 + 编排轻量化」一手复盘，比 demo 级 agent 案例信息密度高得多。

来源：openai.com

llm-d 1.0 首个生产版发布：CNCF 治理、Red Hat/IBM/Google Cloud/CoreWeave/NVIDIA 联合发起，session-aware routing 贴 prefix cache，IBM 量子纠错项目降本 11.5 倍、GLM 5.2（753B）支撑 3000 并发 coding agent 无抢占 ｜ 开源分布式推理栈的标准化节点

1.0 新增多租户隔离、高可用路由、滚动升级不中断、跨云跨加速器稳定配置接口，以及把多轮对话钉在缓存上下文附近的 session-aware routing，后端兼容 vLLM 与 SGLang。硬数据两组：IBM Research 跑量子纠错硬件项目 prefix-cache 命中约 98%、混合成本约 $0.11/百万 token、比全闭源方案低 11.5 倍；GLM 5.2 在现有 NVIDIA GPU 上跑数百并行会话的 agentic 负载，峰值 660 万 output tokens/分钟、单 token 成本比商业 API 低 5-10 倍，输入密集型负载省得最多。AMD、Mistral、JetBrains、Roblox 已在用或计划用。对做推理部署与 agent 成本优化的团队，这是可直接对照的落地参数。

来源：channellife.co.uk ｜ datacentrenews.uk ｜ itbrief.co.uk

生成式推荐为何长期打不过判别式排序：不是自回归 one-to-many 解码的建模劣势，而是 Semantic ID 压缩丢掉了特征交叉依赖的细粒度商品属性 ｜ Shopee UniRec 的工业级一手数据

Shopee 的 UniRec 用三招补齐特征覆盖缺陷：解码 SID 前先 Chain-of-Attribute 预生成商品属性、量化时做曝光加权码本均衡、偏好微调时用逐层 stop-gradient。生产上直接替换多阶段级联，端到端延迟 266ms 降到 110ms，同时 GMV +5.60%、订单 +4.76%。对做召回/排序一体化和语义 ID 的工程师，这条把「生成式推荐的天花板在哪」讲清楚了——差距是特征覆盖缺陷而非建模上限，且给出了可复用的三条工程解法（正文有 paywall，CoA 具体机制与码本均衡公式需读原文核实）。

来源：machinelearningatscale.substack.com

OpenAI 收购 Pierre Computer Company：Codex 里浏览文件的 Trees、看改动的 Diffs、diff 内嵌编辑的 Edit 模式、流式语法高亮 Highlights、用 Git 存历史的 Code Storage 全出自这家 ｜ Codex 把「agent 建分支→人审代码→部署」整条链路收进自家

结合本周早先公布的 Pando 自研 Git 后端，OpenAI 的意图很明确：重做 agent 时代的源码管理标准。Pierre 开源项目保持开源，Code Storage 客户交割后继续可用，交易仍需监管批准。对 coding agent 与开发者工具从业者，这是一份观察大厂如何重做 Git 工作流的路线图；官方公告偏 PR 口径，无技术细节与交易金额。

来源：openai.com

Nathan Lambert 估算开源模型推理经济体量：Fireworks 单一定制模型垂类已超 40T tokens/天、较今夏翻倍以上，总量秋季或超 100T，曲线在 GLM 5.2 带来开源 agent 阶跃后上翘 ｜ 用四家推理创业公司披露数据拼出「开源推理是不是四舍五入误差」

方法上以 Baseten、Fireworks、Together AI 三家开源推理创业公司为风向标，叠加 OpenRouter 的开源模型 token 份额，并与 Google 财报披露的全平台 token 量做量级对比。作者坦承所有开源采用指标都极不精确（平台噪声、创业公司营销口径、不完美的公开评测），因此是「最佳近似」而非定论。对想判断开源推理赛道体量与增长斜率的人，这是难得的跨厂商量级拼图。

来源：interconnects.ai

AWS 把 Anthropic 的 context engineering 建议收敛成四层框架：架构层 multi-agent 隔离上下文、Prompt 层限制摄入、工具层把重内容外置到文件系统、验证层用独立 agent 兜底 ｜ 带可运行代码与量化收益的生产级配方

以开源多 agent 数据分析方案 Deep Insight（Strands Agents SDK + Bedrock AgentCore）为参考实现，每层都点明自身局限由下一层补。量化收益：单个 write-and-execute 工具让每个脚本注入 context 的 token 降约 95%，按需加载 skill 让 system prompt 缩约 97%。对做长时程 agent 的团队，这是一份能直接照抄的工程配方，代价是绑定 SageMaker/Bedrock 技术栈。

来源：aws.amazon.com

MCP server 工程踩坑复盘：模型导入 127 场剧本只重打了 22 场却报告「导入完成」，结论是 tool description 是建议、required parameter 才是规则 ｜ 任何保护用户作品的规则必须由 server 强制

ScreenWeaver 创始人复盘 10 月上线 23 个 MCP 工具（10 读 13 写）的经验：in-app assistant 与外部 MCP 客户端共用一套 server 端 tool registry（同一校验、同一限流 60 次/分）；破坏性工具强制 confirm:true 否则只返回 preview；付费工具强制 maxCredits，超预算直接 over_budget；写操作自动打版本快照；guide 引用的工具与注册表不一致则测试失败。核心洞察是模型一困惑就会跳过 tool description 和 system prompt，因此 schema 级强制才是唯一可靠边界。对做 MCP server 的人是可直接抄的模式。

来源：hackernoon.com
